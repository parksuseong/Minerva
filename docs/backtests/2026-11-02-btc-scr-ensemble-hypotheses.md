# BTCUSDT 30분봉 SCR 3단 승리확률 앙상블 사전 등록

2026-11-02, 결과를 보기 전에 등록한다. 앞선 단일 모델(`2026-11-02-btc-scr-model-hypotheses.md`) 탈락 뒤 사용자: "모델을 여러개만들어도돼 그래서 앙상블로 판단시키는거지". 표본·라벨·특징은 앞선 등록과 같다(`btc_scr_model.build`). 코드는 `docs/backtests/raw/btc_scr_ensemble.py`. 주문과 연결되지 않는다.

## 앙상블
- 구성원: 능형 로지스틱 λ 3·30·300, kNN k 30·60·120, 나이브 베이즈(학습 5분위 구간, 라플라스 보정), 깊이 1 나무 부스팅(150회, 학습률 0.1)
- 전체 표본 모델 8개 + 국면별 전용 모델 8개(일봉·4시간봉 SCR이 모두 신호와 같은 방향인 신호 / 그 밖, 각 학습 80개 이상일 때)
- 각 구성원의 예측을 그 구성원의 학습 구간 예측 분포에서의 백분위로 바꿔 평균한다(시험 신호끼리 순위를 매기지 않는다)
- 큰 봉 필터: 일봉 또는 4시간봉 SCR이 신호와 반대면 받지 않음(켬/끔 두 경우)

## 고르기와 시험
학습 2017~2022로 맞추고 검증 2023에서 필터 켬/끔 × 점수 문턱 0.0~0.8(0.1 간격) 중 매매 30회 이상이면서 평균 최대를 고른다. 시험 2024-01-01~2026-11-02는 학습+검증으로 다시 맞춘다.

## 판정 (모두 넘어야 통과)
1. 시험 앙상블 AUC의 일 단위 블록 부트스트랩 95% 하한 > 0.5
2. 시험 매매 30회 이상, 비용 0.05%·0.10%에서 평균 플러스, SCR만 매매보다 평균 높음
3. 30분봉 시작 15분 이동에서도 2 유지
4. 상위 5거래 제외 플러스
통과하면 레드팀을 거친다. 서술로 큰 봉 필터만 켠 SCR 매매도 낸다.
