## 모델
M1 = SCR 24개 + 체결 흐름 5개(현물 5분봉, 2017-11 이전은 체결 방향 자료가 없어 빈 값)
- 시장가 매수 비율: 최근 1, 4, 16개 15분봉의 시장가 매수 체결량 / 거래량 − 0.5
- 거래량 배수: 최근 4봉 합 / 지난 96봉 평균의 로그, 최근 16봉 합 / 지난 384봉 평균의 로그
- 표본 밖: 2020~2026

M2 = M1 + 선물 지표 6개(바이낸스 metrics 5분 값, 2021-12~)
- 값 시점: 15분봉 마감 5분 전까지 기록된 마지막 값. 빈 값은 앞 값으로 채운다(과거 값만).
- 미결제약정의 1시간, 4시간, 24시간 로그 변화
- 상위 트레이더 롱·숏 비율의 로그, 전체 계정 롱·숏 비율의 로그, 테이커 롱·숏 거래량 비율의 로그
- 표본 밖: 2023~2026. 2022년 한 해로 학습을 시작한다.

## 판정 (모델마다, 모두 넘어야 통과)
1. 표본 밖 거래 100회 이상
2. 거래당 플러스(비용 0.05%), 0.10%에서도 플러스
3. 구간과 연도
   - M1: 2020~2023과 2024~ 모두 플러스이고, 7년 중 5년 이상 플러스
   - M2: 2023과 2024~ 모두 플러스이고, 4년 중 3년 이상 플러스
4. 15분봉 시작 5분·10분 이동에서도 2의 0.05%가 플러스
5. 상위 5거래를 빼도 플러스
6. 선물+펀딩도 플러스
7. 무작위 대조: 해마다 같은 수, 같은 방향 구성, 같은 청산(2,000회). 모델이 둘이라 p<0.025다.
