# 시장 점검 절차

인자: 심볼 목록 (없으면 기본 세트 `SPY QQQ SOXX ^VIX ^KS11 BTC-USD`).
한국 종목은 `.KS`(코스피) 또는 `.KQ`(코스닥)를 붙인다. 예: `005930.KS`

1. **데이터**: `.venv/bin/python -m minerva.strategy.report ^VIX ^VIX3M SPY <심볼...>`를 실행한다. 네트워크가 실패하면 그대로 보고하고 추정하지 않는다.
2. **변동성 레짐**: `vol-regime` 스킬로 R0~R4와 정상화 신호 개수를 판정한다. 이 결과가 전체 노출 한도를 정한다.
3. **종목별 TM**: `momentum-tm` 스킬로 월→주→일 순서로 정렬을 판정한다. 레버리지 상품은 기초자산으로 바꿔서 본다.
4. **리스크**: `risk-rules` 체크리스트를 통과시킨다. 통과하지 못한 항목이 있으면 결론은 관망이다.
5. **반대 검토**: 결론에 롱이나 숏이 하나라도 있으면 `risk-officer` 에이전트에게 결과를 넘겨 반박을 받는다. 반박이 타당하면 반영한다.
6. **보고**: 아래 형식으로 짧게 쓴다. 텔레그램으로 묻는 경우 표 대신 목록을 쓴다.

```
📅 기준일 / 미확정 봉 여부
🌡 변동성: R? · 정상화 n/4 · 주식 노출 권고
📊 종목별
 - XXX: 월/주/일 상태 → 결론(롱·숏·관망), 진입·무효화·목표, 신뢰도
⚠️ 반대 시나리오 한 줄
투자 판단과 책임은 본인에게 있습니다.
```
