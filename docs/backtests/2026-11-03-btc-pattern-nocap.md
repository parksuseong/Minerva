# 패턴 12종 하루 상한 없이 다시 보기 (사전 등록)

2026-11-03, 결과를 보기 전에 등록한다. 청산 규칙 분리 비교(`2026-11-03-btc-scr-exit-iso.md`)에서 하루 상한이 SCR을 나쁘게 했다. 패턴 시험(`2026-11-02-btc-swing-patterns-hypotheses.md`, `2026-11-02-btc-book2-hypotheses.md`, 고친 탐지기 `2026-11-02-btc-pattern-fix.md`)도 하루 상한을 썼으므로, 상한만 1,440봉(30일)으로 늘려 같은 코드로 다시 돌린다. 나머지(진입, 손절·목표, 비용, 판정 1·2)는 각 등록과 같다.

판정은 각 등록의 판정 1·2(2017~2023과 2024~ 각각 30회 이상, 두 구간 플러스, 전체 한쪽 0.10% 플러스)를 그대로 쓰고, 통과 칸은 15분 이동과 상위 5거래 제외로 확인한 뒤 레드팀을 거친다.
