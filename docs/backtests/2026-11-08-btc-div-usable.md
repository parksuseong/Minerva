# BTC 다이버전스를 실시간으로 쓸 수 있는가 — 진단 먼저 (2026-11-08) — 사전 등록

결과를 보기 전에 적는다. 연구 전용(주문 없음, 바이낸스 POST 없음). 앞 시험: `2026-11-08-btc-pine-div.md`(36개 통과 0).

## 왜

사용자의 다이버전스 지표(RSI14·CCI20, 피벗 5/5, 거래량 등급)는 15분·30분에서 피벗 봉 기준 1시간 방향 적중 79~88%였지만,
확정 봉(피벗 + 5봉) 기준 52~54%였다. 사용자는 "10개 뜨면 8개는 방향이 맞는다, 추세전환의 신호탄"이라고 확신한다.
이번 시험은 "어떻게 하면 실시간으로 쓸 수 있는가"를 공정하게 본다. 주로 진단, 규칙은 진단이 문을 열 때만.

## 고정 (앞 시험과 같음)

- 자료: 바이낸스 USDT-M BTCUSDT 선물 5분봉으로 만든 15분·30분·1시간·4시간·1일봉, 체결·경로 = 1분봉, 펀딩 포함. 빈 꼬리는 공개 GET klines.
- 신호: `pine_div.signals`와 같은 논리, 오른쪽 봉 수 R만 바꾼다. 피벗(왼쪽 5, 오른쪽 R): 왼쪽 5봉보다 엄격히 낮고 오른쪽 R봉 이하.
  확정 = 피벗 + R봉 마감. 바로 앞 같은 R 피벗과 비교. 등급 S/M/W **전부(ALL)** 를 쓴다(사용자가 차트에서 보는 모든 라벨). 숏은 거울.
- 기준 가격: 시각 T의 가격 = T 직전 1분봉 종가. 현실 = 확정 봉 마감, 사후 = 피벗 봉 마감(차트 라벨 자리, 비현실, 비교용).
- 구간: fresh 2020-03~2021-10, design 2022-01~2024-06, val 2024-07~2025-10, year 2025-11~, pool 2020-03~2025-10.
- 무작위(시각 맞춤): 신호마다 20개, 같은 봉 주기의 마감 시각을 ±15일(15분·30분·1시간) / ±60일(4시간·1일) 안에서 균등하게, 같은 방향.
  p = 정규 근사(실제 적중 대 무작위 비율, 신호 수 기준). 단측(실제 > 무작위).

## 진단

**D1 확정 지연의 값.** 15분·30분, R = 1, 2, 3, 5(왼쪽 5). 각각:
하루 신호 수, 확정 시각 기준 1h·4h·24h 방향 적중 vs 무작위(사후 적중도 같이), 피벗 → 확정 사이 이미 지나간 이동 중앙값(신호 방향 +),
손절 거리 중앙값(확정 가격 → 피벗 극값). 가설 2 × 4 × 3 = **24**.

**D2 상위 봉.** 1시간·4시간·1일, R = 2, 3, 5. 확정 기준 4h·24h·72h·1주 방향 적중 vs 무작위(사후도 같이). 가설 3 × 3 × 4 = **36**.

**D2b "추세 전환" 주장.** 4시간·1일 다이버전스(R = 2, 3, 5)에서, 확정 시각에 체제가 신호 반대일 때
(a) 일봉 T6D(`pine_ports.s6_trend_dev` 마지막 신호 방향, 마감 일봉)가 7일 안에 신호 방향으로 바뀌는 비율,
(b) 4시간 방향(마감 봉 CCI20>0·RSI14>50 = 상방, 둘 다 반대 = 하방)이 72시간 안에 신호 방향이 되는 비율(시작 상태 = 신호 방향이 아님).
무작위 = 같은 봉 주기 ±60일 마감 시각 중 **같은 시작 상태**인 때, 같은 방향. 가설 2 × 3 × 2 = **12**.

**D3 "10개 중 8개"를 트레이더가 겪는 대로.** 확정 봉 마감 직후 1분봉 시가에 들어갔다고 보고, 신호 방향 +X%(0.5/1/2%)가
피벗 극값 이탈(손절)보다 **먼저** 오는 비율. 1분봉 경로, 같은 분에 둘 다 닿으면 손절 먼저, 최대 14일(둘 다 안 오면 실패로 셈, 비율 따로 적음).
무작위 = 같은 방향, 같은 손절 거리(%)로 위와 같은 시각 맞춤 20개. 확정 가격이 이미 피벗 극값과 같으면(거리 0) 뺀다.
사후판(피벗 봉 종가 진입, 같은 피벗 손절)도 적는다(비교용, 가설 아님). 대상 = D1·D2의 17개 봉·R 조합 × X 3개 = **51**.

**진단 가설 합 24 + 36 + 12 + 51 = 123.** 누적 6,536 + 123 = **6,659**.

### 진단 판정("실시간 우위가 있다")

한 진단 칸이 아래를 모두 만족하면 우위로 본다.
1. pool p × 123 < 0.05 (이 시험 안 Bonferroni). 누적 ×6,659도 따로 적는다.
2. 실제 − 무작위 > 0이 fresh·design·val·year 모두(신호 10개 미만 구간은 빼되, 10개 이상 구간이 3개 이상이어야 함).
3. pool 초과 ≥ 3%p (작은 통계적 차이가 비용을 못 넘는 것은 앞 시험에서 이미 봤다).

## 규칙 (조건부, 최대 8개 — 위 판정을 4시간·1일 진단(D2·D2b·D3) 중 하나라도 통과할 때만 계산)

상위 봉 다이버전스를 설정(setup)으로, 15분 촉발로 같은 방향 진입. 설정 = 4시간 R=3 또는 1일 R=3 다이버전스 확정,
유효 기간 4시간 48시간 / 1일 5일, 피벗 극값이 깨지면 무효. 설정 하나에 거래 하나. 한 번에 1포지션.

| # | 설정 | 15분 촉발 | 손절 |
|---|---|---|---|
| U1 | 4h R3 | 방향 전환: 15분 마감 봉 방향(CCI20·RSI14)이 신호 방향이 됨(직전 봉은 아님) | 4시간 피벗 극값 |
| U2 | 4h R3 | 같은 촉발 | 15분 직전 5봉 극값(촉발 봉 포함) |
| U3 | 4h R3 | 15분 같은 방향 다이버전스 확정(R=2) | 4시간 피벗 극값 |
| U4 | 4h R3 | 같은 촉발 | 15분 다이버전스 피벗 극값 |
| U5~U8 | 1d R3 | U1~U4와 같음 | 같음(4시간 → 1일 피벗) |

- 진입: 촉발 봉 마감 직후 1분봉 시가, 테이커 0.05% + 0.01%. 추격 제한 1%(앞 시험과 같은 3% 예외).
- 청산(사용자 현재 틀): 피벗 손절, +1.5R에서 본전+수수료, +2R에서 1/3 메이커 0.02% 익절, 나머지는 위 봉(1시간) 직전 마감 봉 저/고가 추적, 최대 14일.
- 크기: 1% 위험(5배 상한), 5배 증거금 40%·100%. 선물 + 펀딩, 1분봉 체결.
- 무작위: 같은 설정 기간 안 15분 마감 시각, 같은 방향·손절 거리·청산.
- 판정: 앞 시험 판정 1~5(네 구간 1% 위험·5배 플러스, 무작위 초과 네 구간 + Holm(8) < 0.05, 하루 0.25회는 이 규칙에 맞지 않아 0.03회로 낮춤,
  롱·숏 각 15%, 레드팀 지연·미끄러짐·수수료). 계산하면 누적에 8을 더한다(6,667).
- 계산하면 `chart_d30.png`(최근 30일, 롱 원·숏 삼각형, 롱 진입·숏 청산 초록, 롱 청산·숏 진입 빨강, Stoch·CCI·RSI 칸)와 `equity.png`.
