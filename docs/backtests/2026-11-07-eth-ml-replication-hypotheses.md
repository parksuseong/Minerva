# ETH에서 ML 진입 우위가 재현되는가 사전 등록

2026-11-07 16:41 KST. 이 문서는 결과를 보기 전에 등록한다. BTC 시험 문서로는 143번째다.

## 목적
BTC에서 되풀이해 나온 우위는 ML 진입 시점 하나다(133·134번: AS·AS4·BS·K2가 같은 방향 무작위 진입보다 "+1.5%가 −1.5%보다 먼저 올 확률"이 4~7%p 높다). 이 우위는 모두 BTC에서 찾고 다듬었다. 같은 파이프라인을 고치지 않고 ETH에 그대로 돌려서 우위가 나오면, 진짜일 가능성이 커진다. 나오지 않으면 BTC 결과가 BTC 자료에 맞춘 것일 가능성이 커진다. 코드는 `raw/eth_ml_replication.py`이고, 주문과는 연결되지 않는다.

## 자료
- 특징: BTC 파이프라인은 현물 5분봉으로 특징을 만들었다. ETH 현물 5분봉(`~/.minerva/data/eth/5m.csv`)은 2017-08~2020-03뿐이다. 그래서 2020-01 전은 현물, 2020-01부터는 ETH USDT-M 선물 5분봉(`~/.minerva/data/eth/futures/klines_5m.csv`, 2026-11-07 07:20 UTC까지, 11/06~07은 OKX 377봉)을 이어 붙인다. **BTC와 다른 점이다.**
- 체결: ETH 선물 15분봉과 5분봉. 펀딩: `~/.minerva/data/eth/futures/funding.csv`.

## 모델 (BTC와 같게, 고치지 않음)
- 특징: `btc_ml_ensemble.build(d5, 3)` 28개(15분봉). 라벨: `btc_ml_barrier.barrier_labels(d, 0.015, 0.015)`(다음 봉 시가에서 +1.5%가 −1.5%보다 먼저면 1).
- 걸어가기: 시험 해 2022~2026. 학습은 2018-01부터 시험 해 시작 − 600봉(엠바고)까지, 3봉마다 1개, 정규화는 학습 행으로(`btc_ml_15m.predict`와 같다).
- XGBoost만 쓴다(`fit_predict_tab("xgb")`, 깊이 5, eta 0.05, 300회, subsample·colsample 0.8). 씨드 5벌 Y+1000k(k=0~4). **BTC의 5개 모델(rf, mlp, xgb, lstm, cnn) 대신 씨드 5벌을 "모델 5개"로 쓴다.** 학습이 늦으면 3벌로 줄이고 적는다.

## 규칙 (정의는 BTC와 같다)
- AS-x: `rule_masks(probs, t, 0.90, 4)` — 5벌 평균 점수가 전년 분위수 q0.90 이상(숏 q0.10 이하)이고 5벌 중 4벌 이상이 같은 쪽
- BS-x: `rule_masks(probs, t, 0.95, 5)`
- AS4-x: AS-x + ETH 4시간 EMA50 추세(`btc_ml_tracker.trend4h`, ETH 5분봉)
- K2-x: ETH R1 일봉 방향(`btc_fut_daily_regime.regime`, ETH 선물) 구간마다 첫 같은 방향 AS4-x 신호(`k2_first`), R1 청산(방향 전환·1% 손절, `run_k`)

## 측정
1. 진입 우위(133번과 같은 정의): 체결가에서 2일 안에 +1.5%가 −1.5%보다 먼저 올 확률 − 같은 방향 무작위 진입의 같은 확률. **무작위 진입에도 같은 체결 모형(지정가 −0.1%, 5분 지연, 0.05% 관통, 2봉)을 쓴다**(133 레드팀 지적). 무작위 봉은 같은 달에서 뽑는다(진입마다 20개). 2023과 2024~ 따로.
   - 0 대비 유의성: 진입마다 (적중 − 같은 달·같은 방향 무작위 평균)을 구하고, 달 단위 블록 부트스트랩 2,000회로 평균 ≤ 0 비율을 p로 낸다.
2. 매매: ±1.5%(K2-x는 R1 청산), 현실 체결(5분 지연, 지정가 0.05% 관통), 메이커 0.02%·테이커 0.05%, ETH 펀딩 포함, 1배·3배, 일별 평가(`btc_r1_as4_entry.evaluate`).
3. 연도별 AUC(5벌 평균 점수 vs 라벨).

## 판정 (결과 보기 전에 고정)
통과: AS4-x 또는 BS-x 가운데 하나라도
- 2024~ 진입 우위 > 0이고 블록 부트스트랩 p < 0.05
- 2023 진입 우위 > 0
- 2024~ 매매 1배 거래당 > 0, 롱·숏 각각 ≥ 0

AS-x, K2-x는 참고로 낸다. 비교를 위해 BTC의 같은 규칙 우위(133번, 레드팀이 같은 체결 모형으로 다시 낸 값)를 나란히 둔다. 통과해도 실전 근거가 아니라 "BTC ML 우위가 자료 맞춤만은 아니다"는 근거로만 쓴다.
