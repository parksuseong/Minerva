## 비교
- 기준 모델은 같은 코드로 다시 학습한 XGBoost 단독(28개)이다. 새 모델은 XGBoost 단독(37개)이다. 씨드는 5벌이다(Y + 1000·k, k=0~4). 판정에는 5벌 평균 점수를 쓴다.
- 규칙: A형(전년 상위·하위 10%, q0.90)과 B형(q0.95). 모델이 하나라서 동의 조건은 1개다(점수가 손익분기 확률을 넘을 것).
- 규칙마다 따로 판정한다. 모두 지켜야 통과다.
  1. 새 모델의 2023과 2024~ 3배 누적이 둘 다 플러스이고, 둘 다 기준 모델의 같은 규칙보다 크다.
  2. 최근 1년 3배 누적 > 0이고, 1년 50회 이상 거래한다.
  3. 2024~ 롱과 숏 각각 3배 거래당 > 0
  4. 수수료·밀림 1.5배에서도 2024~ 3배 누적 > 0
  5. 2024~ 점수 원형 이동 200회 대비 p < 0.01
  6. 씨드 5벌 각각으로 같은 규칙을 계산했을 때, 3/5 이상에서 2024~가 기준 모델의 같은 씨드보다 크다.
- 참고로만 보고한다(판정 아님): AUC(2023~), 새 특징 중요도(gain).
- 통과하면 레드팀을 거친 뒤, 추적기에 넣을지 사용자에게 묻는다. 실주문은 없다.
- 2024~는 이미 여러 번 본 구간이다. 통과해도 판정은 결국 기록 추적으로 한다.
