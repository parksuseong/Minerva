# A·B 씨드 바꿔 다시 학습 + MLP 자신감 점검 (사전 등록)

2026-11-04 23:05 KST, 결과를 보기 전에 적는다. 사용자가 서버 자원이 남으니 더 파 보자고 했고, 씨드 확인과 MLP 점검을 골랐다("2번은 빼도돼", 선물 가격 재계산은 뺐다). LightGBM 확인 때 레드팀이 "씨드 하나, 설정 미조정에서 나온 결과"라고 지적한 데서 나왔다. 규칙은 바꾸지 않고 확인만 한다. 지금 돌고 있는 추적기도 그대로 둔다. 코드는 `raw/btc_ml_seeds.py`다.

## 1. 씨드 (A·B가 운인지)
- `btc_ml_15m.predict`와 같은 자료·라벨·걸어가기(2022~2026)로 학습한다. 다른 건 씨드뿐이다: 원래 Y 대신 Y+1000·k (k=1~4, 새 씨드 4개).
- 씨드마다 A(평균 q0.90 + 4/5 동의)·B(q0.95 + 5/5)를 전년 분위수 문턱(`F.thresholds`)으로 다시 정해 `rest_sim`·`summ_net`(3배, 수수료, 펀딩)으로 계산한다. 2023과 2024~를 보고, 롱·숏도 각각 본다.
- 판정(규칙마다 따로):
  - **씨드에 버팀**: 새 씨드 4개 중 3개 이상에서 2023과 2024~ 3배 누적이 둘 다 플러스이고, 2024~ 거래당 3배 기대값(ev3) 중앙값이 원래 씨드 값의 절반 이상.
  - 그렇지 못하면 **씨드에 흔들림**으로 적는다. 지금 성적의 상당 부분이 학습의 무작위성에서 나왔다는 뜻이다. 추적은 계속하되 사용자에게 그대로 알린다.

## 2. MLP 자신감
- 원래 예측(`ml15/pred.npz`)의 2023~ 봉에서 모델마다 확률을 0.1 단위 구간으로 나눠, 구간마다 실제 "+1.5% 먼저" 비율을 본다(보정).
- 판정: MLP가 0.7 이상을 낸 봉의 실제 비율이 0.6 미만이면 **자신감 과다**로 적는다.
- 참고(채택 후보 아님): A·B에서 MLP의 동의가 없었으면 빠졌을 신호 비율, MLP를 뺀 4개 평균으로 계산한 A(3/4 동의)·B(4/4 동의). 이것은 고르기 위한 게 아니라 MLP에 얼마나 기대는지 보려는 것이다.
