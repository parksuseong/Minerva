# RSI 스윙 구간(상승/하락 다리)을 맞히는 ML 분류기 사전 등록

2026-11-07 11:45 KST. 이 문서는 결과를 보기 전에 등록한다. BTC 시험 문서로는 121번째다.

사용자(텔레그램 11:43): RSI Swing Indicator(RSI 7, 70/30)의 HH/HL/LH/LL 화면을 보내며 "이거랑 최대한 비슷한걸 찾아라 어떤방법을 쓰더라도 상관없다 … 고점 저점 모두 발라먹진못하더라도 비슷하게 기계적매매를 할수잇어야해". 114번에서 이 라벨은 확정 전까지 극값으로 옮겨 가므로(다시 그려짐) 그대로는 매매할 수 없었다. 여기서는 사후에 그려진 지그재그를 정답으로 두고, 지금 봉이 어느 다리에 있는지 모델이 맞히게 한다. 코드는 `raw/btc_ml_swing_leg.py`이고, 주문과는 연결되지 않는다.

## 정답(라벨)
- 현물 15분봉, RSI 7. 114번 포팅과 같은 규칙으로 스윙을 잡는다. RSI < 30 구간의 최저가가 저점, RSI > 70 구간의 최고가가 고점이다. 극값이 나온 봉도 기록한다.
- 같은 종류가 연달아 나오면 더 극단인 것 하나만 남겨 고점·저점이 번갈아 오게 한다.
- 저점 극값 봉부터 다음 고점 극값 봉 직전까지는 +1(상승 다리), 고점부터 다음 저점 직전까지는 0(하락 다리)이다.
- 이 라벨은 먼 미래를 본다. 그래서 학습 끝과 시험 시작 사이에 엠바고를 둔다. 엠바고는 "봉 i에서 그 다리를 끝내는 피벗이 확정되는 봉까지 거리"의 최댓값과 2,000봉 중 큰 쪽이다.

## 입력(봉 마감 때 알 수 있는 것만)
- 기존 15분 특징(`btc_ml_ensemble.build`, 현물 5분봉 3개 묶음)
- 추가 5개
  - RSI 7
  - 마지막으로 확정된 스윙 이후 지난 봉 수
  - 마지막 확정 고점·저점과 종가의 거리(%)
  - 마지막 확정 스윙의 종류(저점 +1, 고점 −1)
- 정규화는 학습 구간 행으로만 한다.

## 학습
- XGBoost(max_depth 5, eta 0.05, 300회, subsample·colsample 0.8, nthread 2), 이진 분류
- 연도별 걸어가기 2022~2026. 학습은 2018-01부터 (Y 시작 − 엠바고)까지, 3봉마다 1개
- 씨드 5벌(Y + 1000·k, k=0~4). 판단은 확률 평균으로 한다.

## 매매
- 가격은 USDT-M 선물 15분봉, 펀딩 포함, 시장가 한쪽 0.05%. 3배를 머리로, 1배를 참고로 적는다.
- 문턱: 해마다 전년도 확률 분포의 분위수
  - 2023~: 전년도 시험(표본 밖) 확률
  - 2022: 전년(2021) 확률이 없어서 2022 모델로 2021을 예측한 값(학습 구간과 겹친다)을 쓴다.
- 변형
  - H1: 상위 40%(q0.60) / 하위 40%(q0.40)
  - H2: 상위 20%(q0.80) / 하위 20%(q0.20)
- 진입·청산
  - 확률이 위 문턱을 새로 넘는 봉 마감 → 다음 시가에 롱(숏이면 뒤집기)
  - 아래 문턱을 새로 깨는 봉 마감 → 숏(롱이면 뒤집기)
  - 그 외에는 보유한다.
- 1% 손절(갭이면 시가). 손절 뒤에는 새로 문턱을 넘을 때까지 쉰다.

## 판정 (변형마다, 모두 넘어야 통과; 변형 2개라 p < 0.025)
1. 2023과 2024~ 각각 거래당 순손익 > 0이고 3배 누적 > 0
2. 2024~ 롱과 숏 각각 거래당 > 0
3. 비용 1.5배(한쪽 0.075%)에서 2024~ 거래당 > 0
4. 상위 5거래를 빼도 전체(2022~) 거래당 > 0
5. 예측 확률을 원형으로 민 대조(200회)에서, 전체 거래당이 실제 이상인 비율 p < 0.025
6. 씨드 하나씩 따로 돌려 5벌 중 3벌 이상이 2024~ 거래당 > 0
7. 하루 0.5회 이상

## 같이 적을 것 (판정 아님)
- 닮은 정도
  - 사후 상승 다리 봉 중 롱이었던 비율, 하락 다리 봉 중 숏이었던 비율
  - 같은 방향이었던 봉의 전체 비율
- AUC
- 통과해도 레드팀과 새 자료 확인 전에는 실전에 쓰지 않는다.
