# 추세를 미리 알면 30분봉 SCR이 얼마나 좋아지나 (상한 확인)

2026-11-03, 사용자 질문 "추세를 알면 쓸만한가? 상승장·하락장에서는 승률이 높을 것 같다"에 답하려는 확인이다. 매매 규칙이 아니라 상한을 재는 것이라 통과·탈락 판정은 없다. 코드는 `raw/btc_trend_oracle.py`다.

- 추세(사후): `btc_xgb_trend.labeling`의 일봉 상승·하락 구간(앞으로 60일 가격을 씀). 상승 구간엔 SCR 롱만, 하락 구간엔 숏만 받는다.
- 추세(실시간 대조): 전날 일봉 종가가 60일선 위면 롱만, 아래면 숏만.
- 청산은 반대 30분봉 SCR 신호(필터 없이), 손절 1% 또는 3%. 3배 기준.
