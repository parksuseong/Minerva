# ML 진입 + 짧은 익절(승률 70% 목표) 사전 등록

2026-11-07 22:25 KST. 이 문서는 결과를 보기 전에 등록한다. BTC 시험 문서로는 149번째다.

사용자 목표: 승률 70%, 3배에서 이긴 거래당 +1% 이상. 147·148번(블로그 단타)은 진입 우위가 없어 탈락했다. 승률은 청산 모양이 대부분 정한다. 익절 T, 손절 S일 때 무작위 진입의 승률은 약 S/(T+S)다. 70%와 플러스 기대값을 같이 내려면 진입이 무작위보다 몇 %p 나아야 한다.

130번 격자 결과를 보고 정한 가설이다. AS4 TP1/SL1.5는 2023 승률 67.5%·거래당 +0.136%, 2024~ 63.9%·+0.036%였다. 무작위 기준 약 60%보다 4~7%p 높다. **130번을 본 뒤라 사후 선택의 성격이 있다.** 그래서 무작위 시각 이동 대조와 씨드 기준을 둔다. 코드는 `raw/btc_ml_tight_target.py`이고, 주문과는 연결되지 않는다.

## 규칙
- 진입: 130번과 같은 ML 규칙 B, BS, AS4(5개 모델, BS·AS4는 5씨드 평균, AS4는 4시간 EMA50 추세 문)
  - 지정가 진입, 5분 지연, 0.05% 관통, 메이커 0.02%/테이커 0.05%, 손절 슬리피지
  - 체결과 같은 봉 순서(손절 먼저, 진입 봉 익절 없음)는 130번 `bracket`과 같다.
- 청산 칸 2개:
  - T75: +0.75% 익절 / −1.5% 손절. 무작위 기준 승률은 약 67%다.
  - T50: +0.5% 익절 / −1.0% 손절. 무작위 기준 승률은 약 67%다.
- 칸은 3 × 2 = 6개다. 자료와 예측은 130번과 같다(선물 가격, 2023-01~2026-11-03 13:15 UTC, 펀딩 포함). 구간은 2023 / 2024~로 나눈다.

## 판정 (칸마다, 모두 넘어야 통과)
1. 거래 수: 2023 50회 이상, 2024~ 150회 이상
2. 순승률 70% 이상, 2023과 2024~ 모두
3. 거래당 순손익 > 0, 두 구간 모두. 2024~ 롱·숏 각각 ≥ 0
4. 비용 1.5배에서도 2024~ 거래당 > 0
5. 씨드 평균 규칙(BS, AS4)은 단일 씨드 5개 중 3개 이상에서 2024~ 거래당 > 0
6. 무작위 대조: 신호 시각을 2023~ 안에서 원형으로 민다(300회, 일주일 이상 이동). 2024~ 거래당과 승률이 모두 실제 이상인 비율이 p < 0.0083(0.05/6)
7. 이긴 거래의 평균 순이익 ≥ +0.33%(3배 +1%)

3배 복리와 낙폭도 적는다. 통과해도 실전에는 쓰지 않는다. 추적기 전진 기록으로 확인하고, 레드팀을 거친다.
