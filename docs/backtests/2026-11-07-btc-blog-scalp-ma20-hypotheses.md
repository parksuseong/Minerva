102번(블로그 조합, 반대 신호 청산)은 모두 탈락했다. 이번에는 청산을 블로그의 20선 회귀 익절로 바꾼다. **이 청산은 목표가 가까워 승률이 높게 나오기 쉽다.** 그래서 같은 청산을 쓰는 무작위 진입과 비교해 우위를 따로 판정한다. 일봉 글의 규칙을 15분봉과 1시간봉에 옮긴 것은 내 해석이다. 코드는 `raw/btc_blog_scalp_ma20.py`이고, 주문과는 연결되지 않는다.

## 변형 (롱, 숏은 정확한 거울), 마감된 봉만 사용
- 지표: Stoch Fast 5(20/80), CCI 20(±100), RSI 14(30/70), SMA 5·10·20·60·120, DMI 14(와일더)
- V1 추세 1단: Stoch가 20을 상향 돌파 + 종가 > SMA60 + PDI > MDI + 종가 < SMA20
  - 숏: Stoch 80 하향 이탈 + 종가 < SMA60 + MDI > PDI + 종가 > SMA20
- V3 3단(역배열 제외): SCR 3단 롱(3봉 안 모두 돌파, `scr3`) + 역배열 아님 + 종가 < SMA20
  - 역배열: max(SMA5, 10, 20) < min(SMA60, 120)
  - 숏: SCR 3단 숏 + 정배열 아님(min(5, 10, 20) > max(60, 120)이 아님) + 종가 > SMA20
- 봉: 15분봉, 1시간봉. 변형은 2 × 2 = 4개다.

## 체결과 청산 (5분봉으로 계산)
- 진입: 신호 봉 마감 5분 뒤 5분봉 시가에 시장가로 진입한다. 테이커 수수료 0.05%다.
- 익절: 마지막으로 마감된 그 봉 기준 SMA20에 지정가를 둔다.
  - 5분봉 고가가 지정가보다 0.05% 이상 넘어야 체결로 본다. 메이커 수수료 0.02%다.
  - 시가가 이미 지정가를 넘었으면 시가에 체결로 보고 테이커 수수료 0.05%를 낸다.
- 손절: 진입가에서 1%다. 체결은 손절가(갭이면 시가)에서 0.05% 더 불리하게 잡고 테이커 0.05%를 낸다.
- 같은 5분봉에 손절과 익절이 모두 닿으면 손절로 본다.
- 보유 시간 제한은 없다. 펀딩은 보유 중 정산분을 더하고, 포지션은 하나만 잡는다.
- 자료: USDT-M 선물 5분봉 2020-01~2026-11-07 20:50 KST(11/6 이후 OKX). 앞 60일은 준비 구간이다. 구간은 2020~2023 / 2024~로 나눈다.

2. 순승률(수수료·펀딩 뒤 > 0) 70% 이상, 두 구간 모두
3. 거래당 순손익 > 0, 두 구간 모두. 롱·숏 각각 전체 거래당 ≥ 0
4. 무작위 대조: 같은 문 조건(트리거만 빼고, 종가와 SMA20 위치 포함)을 만족하는 봉에서 롱·숏 같은 수를 뽑는다. 같은 체결·청산을 쓴다(2,000회, 구간별 같은 수). 실제 거래당 이상 비율이 p < 0.0125(0.05/4)
5. 상위 5거래를 빼도 거래당 > 0. 비용을 한쪽 0.05% 더 얹어도 거래당 > 0
6. 봉 시작을 옮겨도(15분봉 5·10분, 1시간봉 20·40분) 거래당 > 0, 승률 70% 이상
7. 이긴 거래의 평균 순이익 ≥ +0.33%(3배에서 +1%, 사용자 목표)

3배 복리와 낙폭도 적는다. 통과하면 레드팀과 진입·청산 차트를 거친다. 통과해도 바로 실전에 쓰지 않는다.
