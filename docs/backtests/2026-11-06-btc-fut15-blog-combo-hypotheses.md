## 필터 (블로그 규칙, 거울)
- none: 필터 없음
- MA(R1·R9): 롱은 종가 > SMA50, 숏은 종가 < SMA50
- DMI(R3·R8): 롱은 PDI > MDI, 숏은 MDI > PDI (DMI 14, 와일더)
- HTF(R2·R5): 마감된 4시간봉 CCI > 0이고 RSI > 50이면 롱, 둘 다 아래면 숏
  - 월·주·일봉을 15분봉용 4시간봉으로 옮긴 것은 내 해석이다.
- MACD(R7): 신호 봉의 MACD(12,26,9) 히스토그램이 롱은 > 0, 숏은 < 0
  - 블로그의 "k봉 안 전환"을 같은 봉 조건으로 줄인 것은 내 해석이다.
- DISP(이격도편 R5): 이격도 D50 = 종가/SMA50×100

  - BTC 15분봉 수치가 블로그에 없어 분위수로 정한 것은 내 해석이다.
