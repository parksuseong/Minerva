# 15분봉 마감마다: 모델 확률 + SCR로 롱 진입, "떨어질 확률 + SCR 숏"으로 청산 (현물·롱만·1배)

2026-11-03, 결과를 보기 전에 등록한다. 사용자 계획: "매 봉 마감마다 판단해서 떨어질 것 같으면 SCR과 함께 판단해서 매매". `2026-11-03-btc-ml-barrier-hypotheses.md`에서 장벽 예측은 2024년 이후 상위 10%에서 3~7%p 판별력이 있었다. 사용자가 "지금 돌려봐"라고 했다. 코드는 `raw/btc_ml_15m.py`이며 특성은 `btc_ml_ensemble.build`를 15분봉으로 쓴다(창 길이는 봉 개수 그대로).

## 예측
- 15분봉 i 마감 뒤 다음 봉 시가 기준 +1.5%가 −1.5%보다 먼저 닿을 확률 p(오름). 같은 봉이면 내림으로 친다. 대칭이라 1 − p를 떨어질 확률로 쓴다.
- 모델 5개(RF, MLP, XGB, LSTM, CNN), 해마다 다시 학습(2022~2026, 2018-01부터 전년 말까지, 마지막 600봉 제외, 3봉마다 하나).

## 매매
- 롱 진입: 최근 4봉(1시간) 안에 15분봉 SCR 3단 롱 신호가 있고, 5개 중 3개 이상이 p > 53.3%(본전)이며 5개 평균 p ≥ 53.3% + m. 다음 봉 시가.
- 청산: 최근 4봉 안에 15분봉 SCR 3단 숏 신호가 있고 5개 평균 p < 50%이면 다음 봉 시가, 또는 손절 3%.
- 비용 한쪽 0.05%, 1배, 롱만. m은 0.03 / 0.06 / 0.10 중 2022~2023 누적 수익이 가장 큰 것.

## 판정 (2024-01~, 모두 지켜야 통과)
1. 거래 30회 이상, 누적 > 0, 거래당 평균 > 0.
2. 모델 조건을 빼고 SCR만 쓴 같은 규칙(진입: 최근 4봉 SCR 롱, 청산: 최근 4봉 SCR 숏 또는 손절 3%)보다 누적이 높다.
3. 모델 확률열을 30일 이상 원형으로 무작위 이동한 200회 대비 누적 p < 0.05.

15분 이동 봉 확인은 통과할 때 다음 날 한다. 통과하면 레드팀을 거친다.
