# A·B 씨드 바꿔 다시 학습 + MLP 자신감 점검 (사전 등록)

2026-11-04 23:05 KST, 결과를 보기 전에 적는다. 사용자가 서버 자원이 남으니 더 파 보자고 했고, 씨드 확인과 MLP 점검을 골랐다("2번은 빼도돼", 선물 가격 재계산은 뺐다). LightGBM 확인 때 레드팀이 "씨드 하나, 설정 미조정에서 나온 결과"라고 지적한 데서 나왔다. 규칙은 바꾸지 않고 확인만 한다. 지금 돌고 있는 추적기도 그대로 둔다. 코드는 `raw/btc_ml_seeds.py`다.

## 1. 씨드 (A·B가 운인지)
- `btc_ml_15m.predict`와 같은 자료·라벨·걸어가기(2022~2026)로 학습한다. 다른 건 씨드뿐이다: 원래 Y 대신 Y+1000·k (k=1~4, 새 씨드 4개).
- 씨드마다 A(평균 q0.90 + 4/5 동의)·B(q0.95 + 5/5)를 전년 분위수 문턱(`F.thresholds`)으로 다시 정해 `rest_sim`·`summ_net`(3배, 수수료, 펀딩)으로 계산한다. 2023과 2024~를 보고, 롱·숏도 각각 본다.
- 판정(규칙마다 따로):
  - **씨드에 버팀**: 새 씨드 4개 중 3개 이상에서 2023과 2024~ 3배 누적이 둘 다 플러스이고, 2024~ 거래당 3배 기대값(ev3) 중앙값이 원래 씨드 값의 절반 이상.
  - 그렇지 못하면 **씨드에 흔들림**으로 적는다. 지금 성적의 상당 부분이 학습의 무작위성에서 나왔다는 뜻이다. 추적은 계속하되 사용자에게 그대로 알린다.

## 2. MLP 자신감
- 원래 예측(`ml15/pred.npz`)의 2023~ 봉에서 모델마다 확률을 0.1 단위 구간으로 나눠, 구간마다 실제 "+1.5% 먼저" 비율을 본다(보정).
- 판정: MLP가 0.7 이상을 낸 봉의 실제 비율이 0.6 미만이면 **자신감 과다**로 적는다.
- 참고(채택 후보 아님): A·B에서 MLP의 동의가 없었으면 빠졌을 신호 비율, MLP를 뺀 4개 평균으로 계산한 A(3/4 동의)·B(4/4 동의). 이것은 고르기 위한 게 아니라 MLP에 얼마나 기대는지 보려는 것이다.

### MLP
- 판정: **자신감 과다**다. MLP가 0.7 이상을 낸 봉 44,238개의 실제 비율은 0.568이었다. 0.9 이상 구간도 실제 0.586이고, 0.1 미만 구간은 실제 0.481이다. 다른 4개는 대부분 0.3~0.7을 내고 대체로 보정돼 있다.
- MLP는 순위(방향)는 제일 잘 맞힌다. 구간이 오를수록 실제 비율도 올라가고 AUC가 .545로 가장 높다.
- 참고: A 신호의 38%(22,312개 중 8,434개)는 MLP 동의가 없었으면 빠졌다. B는 5/5 조건이라 정의상 100%다. MLP를 뺀 4개로 같은 규칙을 계산하면 2024~ A −67.0%, B −37.5%다.

## 레드팀 (2026-11-04)
- 코드 버그는 없다. 원래 씨드 결과도 이전 문서 숫자와 똑같이 다시 나온다. A 일부 씨드는 기대값이 살짝 플러스인데 누적이 마이너스다. 3배에서 생기는 변동성 손실 때문이고 버그가 아니다.
- A가 씨드 운이었다는 판단은 맞고, 오히려 너그러운 편이다. A 신호 봉은 씨드끼리 35~44%만 겹친다(점수 상관 약 0.7). 씨드마다 다른 봉을 고르고, 원래 씨드의 우위는 다른 씨드로 옮겨 가지 않았다.
- B는 "작은 우위가 있을 수도 있지만 증명되지 않음"이다.
  - 근거: 2024~가 씨드 5개 모두 플러스이고, 새 씨드 4개 평균 기대값 0.26은 약 1.5~2 표준오차다.
  - 반대 근거: 2024~는 B를 고를 때 이미 본 구간이다. 2023은 2/4가 마이너스다. 씨드마다 롱(s3)이나 숏(s4) 중 버는 쪽이 바뀐다.
- 기록 추적에 대해: 지금 추적기는 씨드 Y 모델 한 벌이다. A는 기대값 약 0으로 봐야 한다. B는 거래당 0.1~0.25% 정도로 보되 오차가 크다. 1년 약 140회로는 몇 달 기록해도 0.2%와 0을 구분하기 어렵다. 가상 기록만 하고 돈 결정에 쓰지 않는다.
- 다음 단계 제안: 씨드 평균 앙상블. 이미 학습한 5벌을 전부 평균하고, 일부 씨드를 고르지 않으며, A·B 규칙은 그대로 둔다. 백테스트는 이미 본 자료라 증거로 치지 않고, 기록 추적으로만 판정한다. 씨드 수·가중치·문턱을 여러 개 시험하면 다시 찾기가 되므로 하지 않는다.
