# 새 기능 개발 절차

1. **요구사항 정리**: 무엇을, 왜 만드는지 한두 줄로 요약하고 애매한 점은 질문한다.
2. **조사**: 관련 코드를 읽고 재사용할 수 있는 것을 찾는다.
3. **계획**: 바꿀 파일과 접근 방법을 짧게 제시한다. 큰 변경이면 사용자 확인 후 진행.
4. **브랜치**: `feat/<주제>` 브랜치 생성.
5. **구현**: `.claude/rules/code-style.md` 준수, 작은 단위로.
6. **테스트**: `.claude/rules/testing.md`에 따라 테스트 추가 후 실행.
7. **보고**: 무엇을 바꿨는지, 테스트 결과, 남은 일을 요약. 커밋은 요청 시 `/commit`.
