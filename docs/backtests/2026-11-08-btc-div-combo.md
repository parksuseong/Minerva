## H1 — 다이버전스를 거르개로 (12개)

기본 규칙(각자 원래 진입·청산·1포지션):
- **NR**: N4D·GT(일봉 NR4 다음 날 첫 돌파, 일봉 T6D 같은 방향, E4 청산: 설계 MFE 22% 익절, 1×ATR 손절, 72시간, 문 반전 청산). 판단 시각 = 돌파 분.
- **DC**: DC24h·GT·S1·T3BE·H96(손절 1%, 익절 3%, +1R 본전+0.1%, 96시간). 판단 시각 = 신호 15분봉 마감.
- **SCR**: 15분 SCR 3단 B0+S1(반대 신호에 청산·반대 진입, 1% 손절). 판단 시각 = 신호 15분봉 마감.
  거르개는 **새 진입만** 막는다(반대 신호가 기존 포지션을 닫는 것은 그대로).

다이버전스 사건 = 30분 R2 ∪ 1시간 R2(세 등급 전부).
- (b) **거부 V·N**: 판단 시각 앞 N시간 안(t − N < T ≤ t)에 **반대 방향** 사건이 있으면 그 진입을 건너뜀.
- (c) **확인 C·N**: 앞 N시간 안에 **같은 방향** 사건이 있을 때만 진입.
- N = 6, 12. 3 가족 × 2 × 2 = **12**.

잰다:
1. **거르개 효과(주 지표)**: 기본 규칙 거래(2020-03~끝, 한 번 실행)를 판단 시각의 사건 유무로 나눠 "남는 거래 − 빠지는 거래"의
   거래당 평균 수익 차이와 승률 차이. 구간별·pool, 부트스트랩 95% 신뢰구간(5,000회), pool 단측 p = 순열 검정(남김/빠짐 표시를 섞음, 10,000회).
   이 비교가 곧 같은 기하·같은 문의 무작위다(같은 규칙의 거래 중 무작위로 같은 수를 빼는 것과 같다).
   "남는 거래 − 기본 전체" 차이와 신뢰구간도 적는다(겹치는 표본이라 설명용).
2. 거른 규칙을 다시 돌린 결과(1포지션, 빠진 자리에 다른 신호가 들어갈 수 있음): 구간별 거래·하루·롱/숏·승률·거래당 평균, 1% 위험, 5배 40%·100%, 청산.

H1 판정(안 하나가 "쓸 만한 거르개"): ① 순열 p를 12개 Holm < 0.05, 그리고 차이 > 0이 네 주구간 모두(남김·빠짐 각 5개 이상인 구간, 3개 이상 필요)
② 거른 규칙의 1% 위험·5배 40%·100% 네 구간 플러스, 청산 0 ③ 롱·숏 각 15% 이상 ④ 레드팀(지연 1분·1봉, 미끄러짐 +0.02%, 수수료 1.5배) val·year 1% 위험 플러스.
하루 횟수 조건은 없다(거르개는 횟수를 줄인다) — 대신 그대로 적는다.

## H2 — 방향 × 크기 (진단 2 + 규칙 1)

- 큰 움직임 표시 = `leads_ens.all_down`(15분봉 마감 기준 일봉·4시간·15분 모두 CCI20 < 0 이고 RSI14 < 50).
- 대상 = 1시간 R2 다이버전스(세 등급) 중 확정 시각 T에 표시가 켜져 있거나 T 앞 24시간 안에 켜졌던 것(롱·숏 모두).
- **진단(2칸)**: 확정 직후 1분봉 시가 진입, 손절 = 피벗 극값, 신호 방향 +1% / +2%가 손절보다 먼저(최대 14일, 같은 분이면 손절).
  무작위 = 신호마다 20개, ±15일 1시간봉 마감 시각 중 **같은 표시 조건(앞 24시간 안 표시)** 인 시각, 같은 방향, 같은 손절 거리(%).
  p = 정규 근사(신호 수 기준). 설명용으로 표시 없는 1시간 R2 다이버전스도 같은 방식으로 적는다(가설 아님).
- **규칙 H2R(1)**: 같은 대상, 확정 직후 1분봉 시가 진입, 손절 피벗 극값, 사용자 청산 틀(+1.5R 본전+수수료, +2R에서 1/3 메이커 익절,
  나머지 위 봉 = 4시간 직전 마감 봉 저/고가 추적, 최대 14일). 진단 결과와 무관하게 계산한다.
  무작위 = `pine_div.random_for`에 **표시 문**을 넣어 같은 표시 조건 시각만, 같은 방향·손절 거리·청산, 100회.

## H3 — 여러 봉 다이버전스 일치 (진단 2 + 규칙 1, 조건부)

- 사건 = 15분 R2, 30분 R2, 1시간 R2. 어떤 사건이 확정된 시각 T에, **다른 봉**의 같은 방향 사건이 [T − 2시간, T]에 있으면 신호.
  같은 방향 신호가 앞 2시간 안에 이미 나왔으면 건너뜀(한 무리에 하나). 손절 = 2시간 안 같은 방향 사건들의 피벗 극값 중 가장 바깥.
- **진단(2칸)**: H2와 같은 +1% / +2% 먼저. 무작위 = ±15일 15분봉 마감 시각, 같은 방향, 같은 손절 거리, 20개.
- **규칙 H3R(1)**: 진단 판정을 한 칸이라도 통과할 때만 계산. 15분봉 매매(신호 시각 직후 1분봉 시가), 손절 위와 같음,
  사용자 청산 틀, 추적 = 1시간 직전 마감 봉. 무작위 `random_for` 100회.

진단 판정(칸 하나): pool p × 18 < 0.05, 무작위 대비 초과 > 0이 네 주구간 모두(신호 10개 이상 구간, 3개 이상 필요), pool 초과 ≥ 3%p.

규칙 판정(H2R·H3R): ① 네 구간 1% 위험·5배 40%·100% 플러스, 청산 0 ② 무작위 거래당 초과 네 구간 플러스 + pool p Holm(2) < 0.05
③ 하루 ≥ 0.03회(design·year) ④ 롱·숏 각 15% ⑤ 레드팀 val·year 1% 위험 플러스.

## Bonferroni

H1 12 + H2 진단 2 + H2R 1 + H3 진단 2 + H3R 1 = **18**(H3R은 계산하지 않아도 센다). 누적 6,667 + 18 = **6,685**.
누적 기준 p × 6,685도 따로 적는다.
