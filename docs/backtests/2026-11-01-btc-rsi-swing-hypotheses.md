# BTCUSDT 15분봉 RSI Swing 지표 사전 등록

2026-11-01, 결과를 보기 전에 등록한다. 사용자가 BalintDavid의 TradingView "RSI Swing Indicator" Pine 코드를 보냈다. 말로 지시하지는 않았고, 이전 대화 흐름에 따라 매매 신호로 시험한다. 코드는 `docs/backtests/raw/btc_rsi_swing.py`다. 주문과 연결되지 않는다.

## 규칙 (원본 기본값 RSI 7, 70/30)
- 상태: RSI ≥ 70이면 마지막 극단 = 과매수, RSI ≤ 30이면 과매도
- 매수 신호: 마지막 극단이 과매도인데 RSI ≥ 70. 매도 신호는 반대
- 봉 마감 신호, 다음 봉 시가 진입, 반대 신호에서 뒤집기, 손절 1%(사용자 규칙). 비용 한쪽 0.05%

원본의 HH·HL·LH·LL 라벨은 새 고점이나 저점이 나올 때마다 뒤로 옮겨 가므로 실시간 신호로 쓰지 않는다. 비교용으로 "라벨 위치에서 체결했다면"의 값을 낸다.

## 판정 (2020~, 모두 넘어야 통과)
