# BTCUSDT 30분봉 차트 패턴 돌파 + 거래량 확인 사전 등록

2026-11-02, 결과를 보기 전에 등록한다. 사용자가 차트 분석 기법 글과 거래량 정리 글 두 편을 보내며 "네걸로 만들어 매매에 응용할수있도록 해"라고 했다. 정리본은 저장소 밖 `~/.minerva/research/volume_and_methods_notes.md`. 글들의 공통 주장: 차트 패턴은 돌파 확인 뒤 진입, 형성 중 거래량 감소, 돌파 때 거래량 급증. 코드는 `docs/backtests/raw/btc_breakout_volume.py`. 주문과 연결되지 않는다.

## 대상
고친 탐지기(`2026-11-02-btc-pattern-fix.md`)의 돌파형 패턴: 이중 바닥, 삼중 바닥, 역머리어깨, 상승 삼각. 롱·숏(숏은 이중 천장, 삼중 천장, 머리어깨, 하락 삼각), 지그재그 2%·4%. 진입은 돌파 종가 다음 봉 시가, 손절·목표는 책대로, 48봉 안에 결판 없으면 그 시가 정리, 비용 한쪽 0.05%, 승리는 비용 뒤 +0.1% 초과.

## 변형
- V0: 거래량 조건 없음
- V1: 돌파 봉 거래량 ≥ 직전 20봉 평균의 1.5배
- V2: 형성 중 거래량 감소(돌파 직전 40봉 평균 < 그 앞 40봉 평균). 패턴 구간을 정확히 쓰지 않은 대리 지표다
- V3: V1과 V2 모두

## 판정 (묶음 ALL = 네 패턴 합침, 롱·숏, 변형별)
1. 2017~2023과 2024~ 각각 30회 이상
2. 두 구간 기대 손익 플러스(한쪽 0.05%), 전체 한쪽 0.10% 플러스
3. 30분봉 시작 15분 이동에서도 2 유지, 상위 5거래를 빼도 전체 플러스
4. 거래량 조건의 효과(서술): V1·V3이 V0보다 나은가. 같은 수를 무작위로 뽑은 V0 부분집합과 비교
