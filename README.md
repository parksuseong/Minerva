# Minerva 🦉

국내 주식 자동매매 봇과, 그 판단 근거를 보여주는 웹 화면입니다.
매일 코스피 지수와 시가총액 상위 200종목을 분석하고, 백테스트로 검증된 규칙만 한국투자증권 계좌로 주문합니다.
Claude(미네르바)와 서브에이전트들이 일하는 모습은 🏢 오피스 탭에서 실시간으로 볼 수 있습니다.

- 사이트: https://minerva-ai.duckdns.org/
- 언어·도구: Python 3.9+, FastAPI, systemd 타이머, 텔레그램 알림

> ⚠️ 개인 투자용 프로젝트입니다. 백테스트 수익은 미래 수익을 보장하지 않습니다.

## 화면

| 탭 | 내용 |
|---|---|
| 🎯 오늘 할 일 | 오늘 낼 주문(매수·청산·인버스), 변동성 레짐, 자동매매 상태(실전/모의, 중지 여부) |
| 📈 종목 분석 | 종목별 지표와 삼중 모멘텀 상태, 검증 판정(검증됨/부적합/미검증), 대기 가격 |
| 💼 계좌 | 잔고·주문·체결과 수익률(누적·오늘·봇 손익) |
| 🏢 오피스 | Claude와 요원들이 일하는 모습 (아래 [에이전트 오피스](#에이전트-오피스) 참고) |

## 매매 전략 요약

- **대상**: 국내만 실제로 매매합니다. 코스피 시총 상위 200(보통주), KODEX 200, KODEX 인버스(1배)가 대상입니다. 미국·코인 신호는 참고용으로만 보여줍니다. 레버리지·곱버스 상품은 다루지 않습니다.
- **진입 규칙**: 삼중 모멘텀 눌림(TM) 규칙 하나만 씁니다. 인버스는 코스피 되돌림 숏 규칙을 따릅니다.
- **롱 매수 관문**: VIX 주봉 5주선이 10주선 아래일 때만 새로 삽니다. 지난주 마감 기준입니다.
- **종목 검증**: 종목마다 자기 차트로 규칙을 백테스트합니다. 거래 30회 이상, 표본 안·밖 모두 비용 차감 후 우위가 있어야 합니다. 그다음 무작위 타이밍 대비 p값에 다중 검정(BH, q=0.20)을 걸어 우연히 통과한 종목을 걸러냅니다. 판정은 주 1회 다시 계산합니다.
- **비중**: 개별주 30%, 지수 ETF 60%, 인버스 합계 30%에 변동성 레짐 계수를 곱합니다. 최대 10종목입니다.
- **주문**: 매수는 전일 종가 +3% 지정가, 매도·손절은 시장가로 냅니다. 남는 현금은 CD금리 ETF에 넣어 둡니다.
- **안전장치**: `HALT` 파일이 있으면 매매를 멈춥니다. 봇 손익이 고점보다 평가액의 15% 넘게 줄면 신규 매수만 멈춥니다. 통신 오류일 때만 주문을 다시 내고, 다시 내기 전에 중복 주문인지 확인합니다.

자세한 규칙은 [`CLAUDE.md`](CLAUDE.md)와 [`.claude/skills/`](.claude/skills/)의 플레이북에, 검증 기록은 [`docs/backtests/`](docs/backtests/)에, 다음 할 일은 [`docs/ROADMAP.md`](docs/ROADMAP.md)에 있습니다.

## 구조

웹 서버는 화면만 보여주고, 계산·조회·주문은 각각 다른 프로세스가 파일로 주고받습니다. 증권사 키는 조회·주문 프로세스만 읽습니다.

```
 minerva-daily.timer ─ 09:10·16:30 종목 분석 ─┐
 minerva-account.timer ─ 30초마다 잔고 조회 ──┼─▶ ~/.minerva/*.json ─▶ minerva (웹, 읽기 전용)
 minerva-trade-*.timer ─ 점검·주문·손절·대사 ─┘                          https 443
        │
        └─▶ 한국투자증권 API   (알림은 모두 텔레그램)
```

| 시각 (평일, KST) | 작업 | 코드 |
|---|---|---|
| 08:40 | 사전 점검(preflight): 모드·토큰·계좌·분석 최신 여부·휴장일·타이머 | `trade.py` |
| 08:50 | 장전 주문 (매도가 있으면 매도만) | `trade.py` |
| 09:02 | 매도 대금으로 매수, 남은 현금 CD ETF 파킹 | `trade.py` |
| 장중 30초 | 손절 감시 | `trade.py` |
| 09:10·16:30 | 종목 분석 → 텔레그램 요약 | `strategy/daily.py` |
| 15:45 | 잔고 대사, 청산 기록 | `trade.py`, `perf.py` |
| 16:00 | 운용 점검 | `audit.py` |
| 16:10 | 상태 백업(텔레그램) | `backup.py` |
| 16:45 | 다음 날 주문 미리보기 | `trade.py` |
| 금 17:00 | 주간 성과 리포트 | `perf.py` |

```
src/minerva/
├── main.py, routes.py     # 웹 서버와 읽기 전용 API
├── kis.py                 # 한국투자증권 조회
├── trade.py               # 자동매매 (점검·주문·손절·대사·미리보기)
├── perf.py, audit.py      # 실전 성과, 운용 점검
├── office.py              # 오피스 패널 API
├── static/                # 화면 (index.html, *.js, office.css)
└── strategy/
    ├── indicators.py      # 지표
    ├── daily.py           # 일일 분석과 종목 검증
    ├── backtest.py        # 규칙 백테스트
    ├── portfolio.py       # 실전 규칙 포트폴리오 백테스트
    └── walkforward.py     # 시점별 재검증(워크포워드) 유니버스
deploy/                    # systemd 서비스·타이머
scripts/                   # 오피스 훅
```

## 설치와 실행

```bash
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
.venv/bin/pytest                                   # 테스트
.venv/bin/ruff check . && .venv/bin/ruff format .  # 린트·포맷
```

서버와 타이머는 `deploy/`의 systemd 파일로 설치합니다. 각 파일 맨 위 주석에 설치 명령이 있습니다.

비밀값은 저장소 밖에 둡니다. 절대 커밋하지 않습니다.

| 파일 | 내용 |
|---|---|
| `~/.minerva/kis.env` | 한국투자증권 앱 키·계좌 |
| `~/.minerva/telegram.env` | 텔레그램 봇 토큰 |
| `~/.minerva/tls/` | HTTPS 인증서 |

실주문은 `~/.minerva/trade/mode` 파일 내용이 `live`일 때만 나갑니다. 기본은 모의 실행입니다.

### 자주 쓰는 명령

```bash
python -m minerva.strategy.report 005930.KS ^KS11            # 지표 값
python -m minerva.strategy.backtest --help                   # 규칙 백테스트
python -m minerva.strategy.portfolio --start 2021-10-29      # 포트폴리오 백테스트 (오늘 검증 목록)
python -m minerva.strategy.portfolio --walk-forward          # 시점별 재검증 (수 시간, 중단 후 이어서 실행)
python -m minerva.trade preview                              # 다음 날 주문 미리보기 (주문 안 냄)
python -m minerva.audit                                      # 운용 점검
```

## 에이전트 오피스

🏢 오피스 탭은 Claude Code가 이 저장소에서 일하는 모습을 작은 사무실로 보여줍니다.
Claude Code 훅(`scripts/office_hook.py`)이 이벤트를 `~/.minerva/office/events.jsonl`에 쌓고, 화면이 1.5초마다 `/api/office/events`를 읽어 그립니다.

### 요원

| | 이름 | 에이전트 | 맡은 일 |
|---|---|---|---|
| 🦉 | 미네르바 | Claude 본체 | 지시를 받아 일을 나누고, 요원을 투입하고, 결과를 검토해 보고합니다. 코드 작성·커밋도 직접 합니다 |
| 🦊 | 전략가 | `strategist` | 플레이북 순서로 종목을 점검해 롱·숏·관망 결론과 진입·무효화 가격을 냅니다 |
| 🐻 | 리스크 담당 | `risk-officer` | 전략가의 결론을 반박하고, 비중·손절 위반과 사후 맞춤을 점검합니다 |
| 🐿️ | 백테스터 | `backtester` | 가설을 먼저 고정하고 과거 데이터로 규칙을 검증합니다 |
| 🦅 | 운용 감시관 | `trade-auditor` | 실계좌 주문·보유·손절이 규칙대로였는지 점검합니다. 주문은 내지 않습니다 |
| 🐧 | 리뷰어 | `reviewer` | 바뀐 코드에서 버그·보안·빠진 테스트를 찾습니다 |
| 🐕 🦝 🐱 | 탐색가·설계자·만능 요원 | `Explore`·`Plan`·`general-purpose` | 코드 탐색, 구현 계획, 여러 단계 조사 |
| 🦉 | 분신 | `fork` | 미네르바가 맥락을 그대로 가지고 나눠진 분신입니다. 큰 일을 병렬로 처리합니다 |

요원 정의는 [`.claude/agents/`](.claude/agents/)에 있습니다. 요원을 누르면 맡은 일과 최근 작업이 나옵니다.

### 요원들이 움직이는 방식

| 무슨 일이 생기면 (훅 이벤트) | 화면에서 |
|---|---|
| 세션 시작 (`SessionStart`) | 미네르바 책상에 "☀️ 출근 완료" |
| 새 지시 (`UserPromptSubmit`) | 🧑‍💼 사장님이 사무실 가운데로 걸어와 서류를 건네고, 미네르바 말풍선에 "📄 새 지시 접수!" |
| 도구 사용 (`PreToolUse`) | 그 요원이 들썩이며 일하고(타이핑), 모니터가 깜빡이고, 말풍선에 도구 아이콘과 작업 이름이 뜹니다. 예: ⌨️ 테스트 실행, ✏️ trade.py, 🔍 검색 |
| 요원 투입 (`Agent` 호출 → `SubagentStart`) | "○○ 투입!" 알림과 함께 새 책상이 왼쪽에서 미끄러져 들어오고 "🚶 출근 중" → "💼 업무 시작" |
| 실패 (`PostToolUseFailure`) | 모니터가 빨갛게 바뀌고 "❌ ○○ 실패" |
| 커밋·푸시 | "🎉 커밋·푸시!" 알림, 커밋 수 증가 |
| 확인 요청 (`Notification`) | "✋ 확인이 필요해요!" |
| 요원 업무 종료 (`SubagentStop`) | 잠시 뒤 책상이 오른쪽으로 빠져나가며 퇴근 |
| 작업 끝 (`Stop`) | 미네르바가 "💤 대기 중… 다음 지시 기다리는 중" |
| 45초 동안 이벤트 없음 | "☕ 잠깐 쉬는 중" |
| 19시~07시 | 사무실 조명이 어두워지는 야간 모드 |

화면에는 도구 호출·투입 에이전트·커밋·푸시 횟수와 실시간 연결 표시가 있고, 📜 작업 로그에 최근 작업이 흐릅니다.

### 기록하는 것과 안 하는 것

이벤트 종류, 도구 이름, 짧은 라벨(Bash 작업 설명, 파일 이름)만 기록합니다.
프롬프트 본문, 명령 원문, 파일 내용, 메시지 본문은 기록하지 않습니다.
훅은 어떤 경우에도 정상 종료해서 Claude 작업을 막지 않습니다.

### 설치

```bash
python3 scripts/install_office_hooks.py   # ~/.claude/settings.json 에 훅 등록
```

기본은 토큰 없이 공개입니다. 잠그려면 웹 서비스에 `MINERVA_OFFICE_TOKEN` 환경변수를 설정하고 `?token=...`으로 한 번 접속합니다. 토큰은 그 기기에 저장되고 주소창에서는 지워집니다.
