# 패턴 탐지기 정의 수정 (2026-11-02)

사용자가 "패턴 제대로 찾은거 맞아?"라고 물어, 패턴마다 가장 최근 실제 사례를 그려 보고 두 결함을 찾았다. 결과를 본 뒤의 정의 변경이다. 판정 규칙은 각 등록 문서 그대로이고, 고치기 전과 뒤 값을 모두 남긴다.

## 고친 것
1. 지정가형(하모닉 4종, AB=CD, 쓰리 드라이브, 골든 포켓): 마지막 다리가 한 번에 오지 않아도 D를 기다렸다. 예: 크랩 사례에서 C 다음 3% 넘는 반등이 있었는데 그 뒤 D 체결을 크랩으로 셌다. 마지막 피벗 다음 피벗이 확정되는 봉에서 대기를 취소하도록 고쳤다(`btc_book2.scan`의 `cap`). 확정 봉은 대기에서 뺀다. 지그재그는 새 극값 봉에서 확정하지 않으므로 넣든 빼든 결과가 거의 같고, 빼는 쪽이 보수적이다
2. 이중 바닥, 삼중 바닥, 역머리어깨: 시간 대칭이 없었다. 예: 삼중 바닥 사례에서 L1·L2는 하루, L3는 2주 간격이었다. 구간 봉 수 비 0.5~2(`btc_swing_patterns.sym`), 삼중 바닥은 두 고점 차 ≤ 높이의 30%를 더했다. 0.5~2와 30%는 사례 그림을 보고 다시 돌리기 전에 정했고, 결과를 보고 고르지 않았다

`btc_zone_trigger.py`는 자체 `zones()`를 써서 이번 수정이 들어가지 않았다.
