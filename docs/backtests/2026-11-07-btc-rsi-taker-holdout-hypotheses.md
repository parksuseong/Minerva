# 4시간 RSI 급등 + 매수 체결 강세(RT2) 현물 2017~2019 표본 밖 확인 사전 등록

2026-11-07 16:31 KST. 이 문서는 결과를 보기 전에 등록한다. BTC 시험 문서로는 141번째다.

배경: 139번 레드팀이 규칙 C의 우위를 분해했다(`2026-11-07-btc-indicator-library-hypotheses.md` 끝의 레드팀 절). 우위는 4시간 RSI 기울기가 높고 4시간 시장가 매수 비율이 높을 때 함께 나오고, 15분 Stoch 눌림은 보탬이 없었다. 이 두 조건 규칙(RT2)은 2020~2026 선물에서 **사후에 본 것**이다. 이 규칙 계열에 한 번도 쓰지 않은 자료는 현물 2017-09~2019-12뿐이다(`~/.minerva/data/btc/5m.csv`, 10번째 열 taker_buy_base). 그래서 판정은 이 구간으로만 한다. 레드팀이 지적한 문턱 표류(고정 q90 이상 비율이 해마다 2~20%)를 피하는 롤링 분위수 변형도 함께 등록한다. 코드는 `raw/btc_rsi_taker_holdout.py`이고, 주문과는 연결되지 않는다.

## 특징 (139번과 같은 정의)
- `raw/btc_indicator_library.py`의 `frame_features`를 그대로 쓴다.
  - 4시간 RSI 기울기: `rsi_sl = RSI14 − 3봉 전 RSI14` (175행)
  - 4시간 시장가 매수 비율: 마감된 4시간봉 4개(16시간)의 매수 체결량 합 / 거래량 합 (221~223행)
- 4시간봉은 시각 기준으로 묶고 다 찬 봉만 쓴다(`resample`). 15분봉 마감 시각에 이미 마감된 4시간봉 값만 붙인다(`build`의 `searchsorted(..., "right") − 1`).

## 변형 (고정)
- **RT2-F (고정 문턱):** 139번이 2020-03-01~2022-12-31 선물로 구한 분위수를 숫자 그대로 쓴다.
  - 롱: RSI 기울기 ≥ 9.4867 그리고 매수 비율 ≥ 0.51932 (둘 다 q90)
  - 숏(거울): RSI 기울기 ≤ −9.6636 그리고 매수 비율 ≤ 0.47849 (둘 다 q10)
  - 단점: 현물과 선물의 매수 비율 분포가 다를 수 있다. 그 차이도 결과로 적는다.
- **RT2-R (롤링 문턱):** 각 4시간봉에서, 그 봉보다 **앞선** 4시간봉 2,190개(약 1년)로 구한 q90·q10을 쓴다. 조건은 RT2-F와 같다. 첫 1년은 준비 구간이라, RT2-R의 표본 밖은 사실상 2018-09~2019-12다.
- 진입 신호는 조건이 **새로 참이 되는** 15분봉이다(139번 `edges`와 같다).

## 매매
- 신호 봉 마감 + 5분에 시작하는 5분봉 시가에 시장가 진입한다.
- 익절 +1.5%, 손절 −1.5%, 같은 봉에 둘 다 닿으면 손절이다. 손절이 갭이면 시가로 체결한다. 최대 2일 보유 뒤 종가 청산이다(139번 `outcomes`와 같다).
- 포지션은 하나다. 현물 가격, 펀딩 없음, 수수료 한쪽 0.05%.

## 판정 (현물 2017-09-01~2019-12-31, 변형마다 모두 넘어야 통과)
1. 거래당 순손익 > 0
2. 롱과 숏 각각 거래당 ≥ 0
3. 거래 60회 이상
4. 비용 1.5배(거래당 0.05%p 추가)에서도 > 0
5. 무작위 대조: 같은 롱·숏 구성과 같은 청산, 같은 체결로 신호 시각을 원형으로 민다(1,000회). 실제 이상인 비율 p_shift
6. 0 기준 대조: 진입 월 단위 블록 부트스트랩(10,000회)으로 평균 ≤ 0인 비율 p_boot
- 변형의 p는 max(p_shift, p_boot)다. Holm 보정으로 두 변형 중 작은 p < 0.025, 큰 p < 0.05여야 그 변형이 통과한다.
