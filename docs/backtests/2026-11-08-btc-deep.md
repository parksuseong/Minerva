## 3. A. 변동성 확장 양방향 돌파 (OCO 브래킷)
예측자(15분봉 마감 때 이미 마감된 봉만, 시각 규칙 없음):
| 기호 | 조건 | 판단 시점 |
|---|---|---|
| V0 | 대조군: 조건 없음 | 4시간봉 마감마다 |
| V1 NR7-4h | 방금 마감된 4시간봉 범위가 최근 7개 중 가장 작음 | 4시간봉 마감 |
| V2 NR4-1h | 방금 마감된 1시간봉 범위가 최근 4개 중 가장 작음 | 1시간봉 마감 |
| V3 BBW-1h | 1시간봉 볼린저(20, 2) 폭/중심선 ≤ 직전 30일(720개, 현재 제외) 10% 분위 | 1시간봉 마감 |
| V4 ATRR-1h | 1시간봉 ATR(6)/ATR(48) ≤ 직전 30일 10% 분위 | 1시간봉 마감 |
| V5 SCR-DN3 | 일봉·4시간·15분 방향(CCI20>0·RSI14>50 = 위, 둘 다 아래 = 아래)이 모두 아래가 된 첫 15분봉 | 15분봉 마감 |
| V6 IB-4h | 방금 마감된 4시간봉이 직전 4시간봉 안쪽(고가 ≤, 저가 ≥) | 4시간봉 마감 |
| V7 ANY | V1~V6 중 하나라도 | 위 시점 |

브래킷 범위(2): R2h = 직전 15분봉 8개(2시간) 고가·저가, R8h = 직전 32개(8시간). 반폭(범위/2)이 0.3%보다 작으면 중앙에서 ±0.3%로 넓히고,
3%보다 크면 건너뛴다. 매수 스톱 = 위끝 + 1틱, 매도 스톱 = 아래끝 − 1틱, 한쪽 체결 시 다른 쪽 취소(OCO). 4시간 안 미체결이면 취소.
대기 중이거나 포지션이 있으면 새 셋업은 버린다(한 번에 하나).

손절(2): SM = 범위 중앙, SO = 반대 끝. 위험 R = |체결가 − 손절가|.
청산(3, 모두 최대 48시간 뒤 종가 청산): X2R = 2R 목표(메이커 지정가) + 손절, XTR = +1R 이후 (앞 분봉까지 최고 유리가 − 1R) 추적 손절, 목표 없음,
X24 = 24시간 보유 또는 손절.

체결(보수적): 트리거한 분봉의 체결가 = max(트리거, 그 분 시가) + 1틱 + 미끄러짐 0.01%, 테이커. 체결가가 트리거보다 1% 이상 나쁘면
체결하지 않고 브래킷 취소(스톱 지정가로 추격 한도를 지키는 것과 같음). **같은 분봉에서 양쪽 트리거가 모두 닿으면** 손실이 더 큰 쪽으로 체결된 뒤
그 분에 손절된 것으로 친다. 체결 분봉에서 손절가에도 닿았으면 그 분에 손절(순서를 모르므로 손절 먼저). 목표는 다음 분부터.
손절·시간 청산은 테이커 + 1틱 + 0.01%, 목표는 메이커. 실제 정산 펀딩.

변형 수: 8 × 2 × 2 × 3 = **96개**.

## 4. B. 선물 metrics·테이커 상태 신호
특징(15분봉 i 마감 때 아는 값): r1·r4(1·4시간 수익), oi1·oi4(ln OI 변화 1·4시간, `f_oi1`·`f_oi4`), zC(군중 계정 롱숏 비율 ln의 30일 z, `f_zC`),
tbS1·tbS4(15분봉 `tbv/v`의 최근 4개·16개 합 비율 = 1·4시간 테이커 매수 비중, 2020~). 문턱 qXX는 설계 구간 분위수.
조건이 새로 참이 된 봉에서만 신호(방향마다).

가설(문헌·관행, 결과 전 고정):
| 기호 | 근거 | 롱 | 숏 |
|---|---|---|---|
| B1 OI 동반 추세 | OI가 가격과 함께 늘면 새 돈이 들어온 추세 → 이어진다 | r4 ≥ q90(r4) 그리고 oi4 ≥ q70 | r4 ≤ q10 그리고 oi4 ≥ q70 |
| B2 포지션 정리 움직임 역행 | OI가 줄며 오르면 숏 커버링(새 매수 아님) → 힘이 빠진다 | r4 ≤ q10 그리고 oi4 ≤ q30 | r4 ≥ q90 그리고 oi4 ≤ q30 |
| B3 군중 롱숏 역행 | 소매 계정이 한쪽으로 쏠리면 반대 | zC ≤ −1.5 | zC ≥ +1.5 |
| B4 테이커 흐름 모멘텀(1시간) | 주문 흐름 불균형은 짧게 이어진다 | tbS1 ≥ q90 | tbS1 ≤ q10 |
| B5 테이커 소진(4시간) | 공격적 매수가 몰렸는데 값이 못 오르면 흡수 → 반대 | tbS4 ≤ q5 그리고 r1 ≥ 0 | tbS4 ≥ q95 그리고 r1 ≤ 0 |
| B6 OI 급감 되돌림(오염 계열) | 큰 움직임 + OI 급감 = 강제청산 → 되돌림 | r1 ≤ q5 그리고 oi1 ≤ q3 | r1 ≥ q95 그리고 oi1 ≤ q3 |

진입: 신호 봉 다음 분(15분봉 마감 직후 1분봉 시가) 시장가, 테이커 + 1틱 + 0.01%. 추격 한도: 체결가가 신호 종가에서 1% 이상(15분·4시간·일봉 방향이
모두 신호 쪽이면 3%) 벗어나면 건너뜀. 청산(2): H4 = 4시간 보유, H24 = 24시간 보유, 둘 다 진입가 ∓2% 손절(5배 −10%). 한 번에 하나, 보유 중 신호는 버림.
변형 수: 6 × 2 = **12개**.
