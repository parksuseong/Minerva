# 고서 매매 규칙서: SCR 3단 + 물타기 (익절 10%)

판 2026-11-17 · 코드 `src/minerva/gose_rules_avg.py`(이 문서와 한 줄씩 같음) · 가상 계좌 `avg-SOXL`, `avg-SOXX`

이 문서만 읽고 다른 사람이나 에이전트가 똑같이 매매할 수 있게 썼다. 모르는 칸이 있으면 이 문서가 틀린 것이다.
**미검증 · 실제 주문 없음.** 무작위 진입과 큰 차이가 없다(아래 "솔직한 주의점").

## 1. 대상과 자료

- 종목: 계좌 하나에 한 종목. `avg-SOXL`은 SOXL(반도체 3배 ETF), `avg-SOXX`는 SOXX(반도체 1배 ETF). 다른 종목은 사지 않는다.
- 봉: 일봉 시가·고가·저가·종가(O, H, L, C). 분할 조정, 배당 조정 없음(야후 차트 기본값). 정규장이 끝난 봉만 쓴다(장중의 오늘 봉은 버림).
- 지표는 가진 자료의 첫 봉부터 계산한다(가상 계좌는 2010-01-01부터, SOXL은 2010-03-11 상장일부터).
- 분할이 나면 과거 봉 전체가 새 기준으로 바뀐다. 이때 보유 수량·평단·익절가도 같은 비율로 바꾼다(가상 계좌는 매일 전체 기록으로 다시 계산하므로 자동).

## 2. 지표 (t = 오늘 봉, 마감 값)

```
StochK(5)_t = (C_t − min(L_{t-4..t})) / (max(H_{t-4..t}) − min(L_{t-4..t})) × 100
              분모 0이면 50. 앞 4봉은 값 없음.

TP_i       = (H_i + L_i + C_i) / 3
M_t        = (TP_{t-19} + … + TP_t) / 20
MD_t       = (|TP_{t-19} − M_t| + … + |TP_t − M_t|) / 20
CCI(20)_t  = (TP_t − M_t) / (0.015 × MD_t)
              MD_t = 0이면 0. 앞 19봉은 값 없음.

U_i = max(C_i − C_{i-1}, 0),  D_i = max(C_{i-1} − C_i, 0)
RSI(14)_t  = 100 − 100 / (1 + ΣU / ΣD),  합은 i = t−13 … t (14개, 단순 합, 와일더 평활 아님)
              ΣD = 0이면 ΣU > 0일 때 100, ΣU = 0이면 50. 앞 14봉은 값 없음.
```

## 3. 신호 SIG_t (t봉 종가로 판단)

세 줄이 모두 맞아야 SIG_t다. 값이 없는 지표가 하나라도 있으면 SIG 아님.

```
(1) StochK_t > 20  AND  CCI_t > −100  AND  RSI_t > 30
(2) StochK_{t-1} ≤ 20 < StochK_t  OR  CCI_{t-1} ≤ −100 < CCI_t  OR  RSI_{t-1} ≤ 30 < RSI_t
(3) 창 = [max(t−10, P+1), t−1]  (P = 직전 SIG 봉, 없으면 −1이라 창은 [t−10, t−1])
    창 안에 StochK ≤ 20 인 봉이 하나 이상
    AND 창 안에 CCI ≤ −100 인 봉이 하나 이상
    AND 창 안에 RSI ≤ 33 인 봉이 하나 이상      (RSI만 33: 3 여유)
```

- "직전 SIG"는 실제로 샀는지와 상관없이 자료 첫 봉부터 센 바로 앞 SIG다(보유 중 SIG, 추가 한도를 넘은 SIG, 계좌 시작 전 SIG 모두 포함).
- 세 조건은 같은 봉일 필요가 없다(창 안 아무 봉이나).

## 4. 매매

체결은 언제나 신호 다음 봉(t+1)의 **시가**. 수수료는 편도 0.05%(산 금액·판 금액 각각).

### 4.1 사이클 시작 (무포지션)
- 무포지션이고 SIG_t → t+1 시가에 **1단위** 매수.
- 단위 금액 `unit = (사이클 시작 때 자산) / 3`. 무포지션이므로 자산 = 현금. 이 사이클 안에서는 unit을 바꾸지 않는다.
- 산 수량 = unit / (시가 × 1.0005). 즉 unit에는 수수료가 들어 있다.
- 실계좌라면 수량을 정수로 내려 사고 남는 돈은 현금으로 둔다(가상 계좌는 소수 수량).

### 4.2 물타기 (보유 중 추가)
- 보유 중 SIG_t이고 이 사이클 추가 횟수 < 2 → t+1 시가에 1단위(같은 unit) 추가 매수.
- 추가 횟수가 이미 2면 그 SIG는 아무것도 하지 않는다(그래도 "직전 SIG"로는 센다).
- 최대 투입 = 3단위 = 사이클 시작 자산의 100%. 레버리지·차입 없음, 현금이 모자랄 일 없음.
- 추가 조건에 가격은 없다(평단보다 비싸도 SIG면 산다).

### 4.3 평단과 익절
- 평단 = 총투입금(수수료 포함, 단위 금액의 합) / 보유 수량. 매수할 때마다 다시 계산.
- 익절: **전량** 지정가 매도, 가격 = 평단 × 1.10, 기간 GTC(취소될 때까지).
- 체결 판정(봉마다, 일봉 기준):
  - 시가 ≥ 익절가 → 시가에 체결(갭 위로 열림).
  - 아니면 고가 ≥ 익절가 → 익절가에 체결.
  - 사이클을 시작한 그 봉에는 시가 체결이 없다(주문이 시가 뒤에 생김). 고가 판정은 한다.
- 추가 매수가 있는 날 순서: 시가 전에 기존 익절 주문을 취소 → 시가에 추가 매수 → 새 평단으로 익절가를 다시 계산해 새 주문 → 그 봉 고가로 판정(시가 판정도 위 규칙대로).
- 매도 대금 = 수량 × 체결가 × (1 − 0.0005).

### 4.4 손절·시간·기타
- 손절 **없음**. 보유 기간 제한 **없음**. 익절가에 닿을 때까지 들고 있는다.
- 익절한 봉에서는 다시 사지 않는다(진입은 시가에만 있으므로 같은 봉 재진입은 불가능). 다음 SIG를 기다린다.
- 같은 봉 안 순서: ① 시가 매수(시작·추가) ② 익절 판정 ③ 종가로 평가.
- 공매도·인버스·다른 종목 없음.

### 4.5 계좌를 처음 켤 때와 열린 포지션
- 계좌는 시작일(START)에 무포지션·현금 10,000 USD로 시작한다. START 이전 SIG로 생긴 포지션은 이어받지 않는다(START 당일 이후 봉의 SIG만 쓴다).
- 이미 들고 있는 포지션이 있으면 규칙이 끝날 때까지(익절) 그대로 관리한다. 중간에 규칙을 바꾸지 않는다.
- 가상 계좌는 매일 전체 기록으로 처음부터 다시 계산한다(같은 자료면 같은 결과). 그래서 자료가 고쳐지면(분할 등) 과거 체결도 새 자료 기준이 된다.

## 5. 매일 할 일 (미국 정규장 마감 뒤)

1. 오늘 마감한 일봉을 받아 지표 셋을 계산한다.
2. SIG_오늘인지 본다.
3. 무포지션 + SIG → 내일 시가에 현금/3 매수 예약.
   보유 + SIG + 추가 < 2 → 내일 시가에 unit 추가 매수 예약(익절 주문은 시가 전에 취소, 체결 뒤 새 평단 × 1.10으로 다시).
4. 보유 중이면 익절 지정가(평단 × 1.10, 전량, GTC)가 걸려 있는지 확인한다.

## 7. 솔직한 주의점

- **승률 100%는 손절이 없어서다.** 익절할 때까지 기다리므로 닫힌 사이클은 다 이긴다. 손실은 "아직 안 닫힌 사이클"에 숨어 있다.
- **중간에 크게 빠진다.** 평단 대비 SOXL −75%, NVDA(1배 후보 시험) −43%까지 빠진 사이클이 있었다(그 뒤 회복해 익절).
- **오래 묶인다.** 가장 긴 보유는 1~2년(SOXL 236거래일, SOXX 537거래일).
- **무작위 진입과 큰 차이가 없다.** 같은 횟수로 아무 날 들어가도 수익이 비슷했다(p 0.47, 0.56). 돈을 버는 건 신호가 아니라 "익절 10% + 물타기 2번" 구조다.
- **그냥 들고 있는 것보다 수익이 낮고, 낙폭이 작다.**
- 반도체가 오래 오른 시기의 결과다. 긴 하락장(예: 2000~2002)에서는 3단위를 다 넣고 몇 년 묶일 수 있다.
