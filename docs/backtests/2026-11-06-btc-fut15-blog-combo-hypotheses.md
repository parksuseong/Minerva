## 판정 (검증 구간, 조합마다, 모두 넘어야 통과)
1. 롱·숏 각각 30회 이상
2. 합친 거래당 플러스(0.05%), 0.10%에서도 플러스
3. 롱과 숏 각각 거래당 0 이상(0.05%)
4. 봉 시작 5분·10분 이동에서도 2의 0.05% 플러스
5. 상위 5거래를 빼도 플러스
6. 무작위 대조: 같은 수, 같은 방향 구성, 같은 청산 규칙으로 무작위 봉에 진입한다(2,000회). p < 0.05/k
