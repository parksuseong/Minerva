# 코딩 스타일 (Python)

- Python 3.9+ 호환을 유지한다 (현재 서버 버전 3.9).
- 포맷/린트는 ruff 기준. 줄 길이 100.
- 공개 함수/클래스에는 타입 힌트를 단다.
- 이름: 모듈·함수·변수 `snake_case`, 클래스 `PascalCase`, 상수 `UPPER_SNAKE`.
- 주석은 "왜"를 설명할 때만. 코드가 말해주는 "무엇"은 쓰지 않는다.
- 비밀값(API 키, 토큰)은 코드에 넣지 않고 환경변수/`.env`로 읽는다. `.env`는 커밋 금지.
- 예외는 삼키지 말고, 처리할 수 없으면 위로 올린다.
