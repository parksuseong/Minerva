# 가설 등록부 (2026-10-28 실행 전 고정)

공통: 일봉 야후 데이터 전체 기간, 진입 = 신호 다음 봉 시가, 표본 내 70% / 표본 밖 30%,
비교 기준 = 같은 보유기간 무조건 평균 수익(edge). 중복 이벤트는 최소 간격(gap)으로 제거.
도구: `src/minerva/strategy/events.py` (이벤트 분석), `backtest.py` (규칙 매매).

| ID | 가설 | 성공 기준 |
|---|---|---|
| A | VIX 주봉 5/10 골든크로스 뒤 SPY·QQQ·SOXX 4·8·13주 수익은 무조건 평균보다 낮고, 데드크로스 뒤는 높다 | 표본 내·밖 모두 부호 일치 |
| B | VIX/VIX3M 백워데이션 단계(0~5, 5~15, 15~30, 30%+)가 깊을수록 SPY 20·60일 수익이 높다 | 단계별 edge가 단조 증가 |
| C | VIX 레짐 R0~R3, VIX 50/120/200 정배열(R4)별 SPY 20·60일 수익: R0 > R2·R3, R4는 낮다 | 표본 내·밖 순서 유지 |
| D | VIX 정상화 신호(스파이크 후 5일선 이탈 / RSI 70 하향 / 콘탱고 복귀) 뒤 SPY 20일 edge > 0 | 표본 내·밖 edge > 0 |
| E | VXX가 직전 +10% 반등 뒤 20일 신저가를 내면, 4~12거래일 안에 신저점 대비 +10%가 나올 확률이 무조건 확률보다 높다 | 차이 > 10%p, 표본 내·밖 |
| F | VXX는 달마다 월중 저점 대비 +10% 이상 상승 구간이 나온다 (월빔) | 비율 보고 (구조적 성질인지 확인) |
| G | VIX는 2~4월·8~10월에 상승, 5~7월·11~1월에 하락하는 경향 | 월별 평균 VIX 변화의 부호 |
| H | 정배열(5>10>20>50)에서는 L1, 역배열에서는 L3가 더 낫다 | 해당 조합 edge가 반대 조합보다 큼 |
| I | 일봉 L1 신호 성과는 월·주 방향 조합에서 (상,상) > (상,하) > (하,상) > (하,하) | 순서 유지 |
| J | SOXX 주봉 L3 과매수 이탈 뒤 4·8·13주 수익 < 무조건 평균 (인버스 근거) | 표본 내·밖 edge < 0 |
| K | L3 돌파 뒤 2봉 안에 Stoch 80 이상이면(휩소) 성과가 나쁘다 | 휩소 edge < 비휩소 edge |
| L | ADX ≥ 50에서 역추세 L3 신호는 성과가 나쁘다; +DI > -DI에서 L1이 낫다 | 해당 비교 부호 |
| M | SPY와 VIX가 같은 날 함께 1% 이상 상승하면 이후 10일 VIX 최대 상승폭이 무조건보다 크다 | 차이 > 0, 표본 내·밖 |
| N | SOXL 실제 수익은 같은 기간 SOXX 수익 × 3보다 낮다 (감쇠) | 보유기간별 차이 보고 |
