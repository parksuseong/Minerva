# BTCUSDT mit 조합에 RSI·SCR 조건 추가 사전 등록

2026-11-01, 결과를 보기 전에 등록한다. 사용자: "Rsi 넣고 다시테스트해 scr조건 넣어서". 코드는 `docs/backtests/raw/btc_mit_scr.py`, numpy가 필요하다. 주문과 연결되지 않는다.

## 대상
1시간봉 DMI + RQK + Ichimoku(고승률 탐색 승률 1위). 신호 조건에 아래를 더한 뒤 번갈아 나오는 신호를 만든다. SCR 값은 Stoch fast %K 5, CCI 20, RSI 14, 봉 종가 기준이다.

| 변형 | 롱 조건 | 숏 조건 |
|---|---|---|
| B | 없음 | 없음 |
| V1 RSI 과열 금지 | RSI < 70 | RSI > 30 |
| V2 SCR 과열 금지 | Stoch < 80, CCI < 100, RSI < 70 | Stoch > 20, CCI > −100, RSI > 30 |
| V3 SCR 방향 | CCI > 0, RSI > 50 | CCI < 0, RSI < 50 |
| V4 V2 + V3 | 둘 다 | 둘 다 |

청산은 익절 없음(반대 신호), 1%, 2%, 손절 1%, 비용 한쪽 0.05%. 5 × 3 = 15개.

## 판정 (모두 넘어야 통과)
V1~V4 각 청산에서 2025~26 비용 0.05%·0.10% 플러스, 2020~24 플러스, 거래 100회 이상(2020~26), 같은 청산의 B보다 2025~26 수익이 높음. 통과하면 레드팀을 거친다.

## 알려진 한계
대상 조합은 2020~24 승률 1위로 고른 것이고 2025~26은 앞서 이미 봤다. RSI 70 이상 롱은 2025~26 비교에서 나쁘지 않았고, 이번 조건은 그 결과를 본 뒤 사용자 요청으로 넣었다.
