## 기억과 예측 (미래 정보 차단)

- 기억 = 결정 시점보다 **앞서 끝난** 모든 모양 중, 그 뒤 H봉 결과까지 확정된 것만(결정 시점 − H − 1봉 이전). 계산을 줄이려 기억은 4봉(1시간)마다 하나씩 저장.
- 질문(결정)은 시험 구간의 모든 15분봉 마감에서 한다. 256봉 묶음마다 기억은 묶음 시작 기준으로 자른다(더 보수적).
- K개 최근접(K ∈ {20, 50, 200}). 예측 = 유사도 가중으로 이웃들의 다음 H=8봉(2시간) 수익 부호 투표 → 오를 확률 p.
- 진입: p ≥ q 이고 이웃 평균 수익 > 0 → 롱, p ≤ 1−q 이고 평균 < 0 → 숏. q ∈ {0.6, 0.7}.

## 매매

- 한 번에 한 포지션. 신호 다음 봉 시가 시장가(테이커 0.05%). 추격 한도: 체결가가 신호 종가에서 1% 넘으면 버림(15분·4시간·일봉 방향 모두 같으면 3%).
- 청산: 익절 +1%, 손절 1×ATR14(15분봉), 8봉 지나면 시간 청산. 같은 봉에서 손절·익절이 다 닿으면 손절로 본다.
- 수수료 방식 2개: (a) 테이커 진입·청산, (b) 메이커 진입(신호 종가 지정가, 다음 4봉 안에 그 가격을 1틱 넘게 관통해야 체결, 0.02%) + 테이커 청산.
- 5배 결과(청산: 5×최악 평가손익 ≤ −95%), 1배 참고. 펀딩 포함.
