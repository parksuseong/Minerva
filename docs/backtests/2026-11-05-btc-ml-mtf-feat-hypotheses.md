# 15분 ML에 30분·1시간·4시간·일봉 추세 입력을 넣어 다시 학습 (사전 등록)

2026-11-05 09:10 KST, 결과를 보기 전에 적는다. 사용자가 "응"이라고 답했다. 생각은 "큰 파도는 작은 파도를 삼킨다"이고, 상위 봉 추세가 하위 봉 신호를 이끈다는 것이다. 바로 앞 시험(`2026-11-05-btc-ml-mtf-trend-hypotheses.md`)에서는 4시간 추세 필터가 2023~25에는 도움이 됐고 최근 1년에는 손해였다. 필터로 거르는 대신, 모델이 추세를 입력으로 보고 상황에 따라 다르게 쓰게 하면 나은지 본다. 코드는 `raw/btc_ml_mtf_feat.py`다.

## 바꾸는 것
- 지금 입력(`btc_ml_ensemble.build`)에는 4시간·일봉 Stoch/CCI/RSI, 일봉 60일선, 주봉·일봉 구조가 이미 있다. 여기에 12개를 더한다.
- 30분, 1시간, 4시간, 일봉마다 세 가지다: 종가/EMA50 − 1, EMA50 5봉 기울기(로그 차), 추세(+1/0/−1, 앞 시험과 같은 정의).
- 15분 신호 봉 마감 시점에 이미 마감된 상위 봉만 쓴다.
- 나머지는 바꾸지 않는다: 라벨(+1.5%/−1.5% 먼저), 모델 5개와 설정, 걸어가기(2022~2026, 전년까지 학습, 엠바고 600봉), 학습 표본 1/3, 씨드 5벌(Y + 1000·k, k=0~4).

## 비교
- 기준은 같은 씨드 5벌로 학습한 지금 모델이다(`ml15/pred.npz`, `seeds/pred_s1~4.npz`).
- 규칙은 AS(평균 q0.90 + 4/5 동의)와 BS(q0.95 + 5/5)이고, 문턱은 전년 분위수다. 체결은 `rest_sim`, 비용은 `summ_net`(3배, 수수료, 펀딩)이다.
- 규칙마다 따로 판정한다. 모두 지켜야 통과다.
  1. 새 모델의 2023과 2024~ 3배 누적이 둘 다 플러스이고, 둘 다 기준 모델의 같은 규칙보다 크다.
  2. 최근 1년 3배 누적 > 0, 1년 50회 이상.
  3. 2024~ 롱·숏 각각 3배 거래당 > 0.
  4. 수수료·밀림 1.5배에서 2024~ 3배 누적 > 0.
  5. 2024~ 점수 원형 이동 200회 대비 p < 0.01.
  6. 씨드 5벌 각각으로 같은 규칙을 계산했을 때, 3/5 이상에서 2024~가 기준 모델의 같은 씨드보다 크다.
- 참고로만 보고한다(판정 아님): 새 모델 + 4시간 추세 필터(AS4와 같은 방식), 모델별 AUC.
- 통과하면 레드팀을 거친 뒤, 추적기에 넣을지 사용자에게 묻는다. 실주문은 없다.
- 2024~는 이미 여러 번 본 구간이다. 통과해도 판정은 결국 기록 추적으로 한다.
