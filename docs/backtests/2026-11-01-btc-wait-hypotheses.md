# BTCUSDT 15분봉 기다림 규칙 사전 등록

2026-11-01, 결과를 보기 전에 등록한다. 사용자: "기다려야하는 이유를 찾으면 되는거지?" 규칙 M(`2026-11-01-btc-marked-hypotheses.md`)이 일찍 들어가서 실패했다. 10-29의 좋은 신호와 나쁜 신호 두 쌍을 비교해 찾은 차이를 시험한다.

## 변형 (Stoch 돌파·이탈 봉 기준, 반대 신호에서 뒤집기)
- W1: 최근 3봉 안에 RSI ≤ 30이면 롱, RSI ≥ 70이면 숏. 원문 "3개 모두 과매수 뒤 이탈"과 맞는다
- W2: 마지막으로 마감된 1시간봉 CCI < 0이면 롱, CCI > 0이면 숏
- W3: W1과 W2 둘 다

3봉, 기준선 30·70, CCI 0은 기존 값이다. 다른 값을 찾지 않는다. 손절은 없다. 체결, 비용, 구간은 앞선 시험과 같다.

## 판정 (모두 넘어야 통과)
앞 2017-09-01~2023-12-31, 뒤 2024-01-01~. 세 변형 각각 본다.
1. 앞·뒤 모두 수익/낙폭이 BTC 보유보다 높다
2. 비용 0.10%에서도 뒤 연수익이 플러스다
3. 뒤 구간 수익 상위 5건을 빼도 연수익이 플러스다
4. ±1%에 유리한 쪽이 먼저 닿는 비율이 앞·뒤 모두 53% 이상이고 표본 오차를 넘는다
5. 1~4를 넘으면 레드팀이 무작위 타이밍 p<0.05를 확인한다
