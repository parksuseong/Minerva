# BTC DMI(PDI·MDI 교차) 15분봉 사전 등록 (2026-11-08)

사용자 요청(텔레그램, 6차 보고 뒤): 사용자가 준 DMI 규칙을 비트코인 15분봉에 대입해 "15분봉으로 저 지표를 만들고 매매".
이 문서는 계산 전에 커밋한다. 문턱·청산·변형 수는 아래 그대로 고정하고, 결과를 본 뒤 바꾸지 않는다.

## 사용자가 준 규칙 (원문 요지, 출처 주소는 남기지 않는다)

- 대상은 VIX **주봉** DMI: ADX(14) 검정, PDI 빨강, MDI 파랑.
- "PDI 골든 크로스"(PDI가 올라가며 교차) = 변동성 시작. "PDI 데드 크로스" = 변동성 끝 → 증시 강한 반등.
  MDI 골든 크로스도 끝을 알린다.
- "SCR 이탈이 선행 시그널, PDI 데드는 후행 확인". 신호 속도 SCR > DMI.
- 그림의 교차 상대가 ADX 선인지, MDI인지, 20 수준선인지 분명하지 않다. 세 가지 읽기를 모두 따로 등록한다(사후에 고르지 않는다).

BTC 15분봉으로 옮기면 바뀌는 점: 원래는 VIX(변동성 지수) 주봉의 "변동성 끝"을 주식 반등으로 읽는 신호다. BTC 가격 자체의 DMI는
추세 방향 지표가 된다. 그래서 두 해석을 둔다 — 추세 시작(따라가기)과 움직임 끝(되돌림, 글의 실제 쓰임).

## 공통 틀 (5·6차와 같음)

- 자료: 바이낸스 BTCUSDT 선물 15분봉 + 펀딩(5차 자료 `~/.minerva/research/round5-2026-11-08`).
- 구간: 새 구간 2020-03~2021-10, 설계 2022-01~2024-06, 검증 2024-07~2025-10, 이미 본 구간 2025-11~(보고만), 최근 30일(보고만).
- 체결: 신호 봉(상위 시간대면 그 봉의 마지막 15분봉) 마감 → 다음 15분봉 시가 시장가. 테이커 0.05%/편, 펀딩 실제 값.
  같은 봉에서 손절·목표 둘 다 닿으면 손절 먼저. 포지션은 겹치지 않는다(반대 신호면 청산 후 뒤집기).
- 레버리지: 10배 머리값(최악 평가손익 × 10 ≤ −95%면 청산), 1·3·5배 함께 보고.
- 무작위 기준: 같은 구간·같은 청산 모양, 진입 시각만 무작위(롱·숏 수 같게), 2,000회. 본페로니 = 이번 변형 수 145.
- 통과 기준(전부): 검증 승률 ≥ 70%, 검증 10배 > 0, 검증·설계 청산 0, 검증 ≥ 30회, 설계 1배 > 0,
  새 구간 승률 ≥ 70%·10배 > 0·청산 0·≥ 20회, 검증 무작위 대비 1배 p(본페로니) < 0.05.
- 레드팀: 이 작업은 하위 에이전트를 띄울 수 없어 스스로 같은 점검(1봉 지연, 수수료 1.5배, 해별 손익)을 한다.

## 지표

- DMI(14, 와일더): +DM/−DM, TR을 RMA(14)로 평활, PDI = 100·RMA(+DM)/RMA(TR), MDI 같음, ADX = RMA(DX, 14).
- 시간대 TF ∈ {15m, 1h, 4h, 1d}. 상위 시간대는 완결된 봉으로만 계산(UTC 경계), 신호는 그 봉의 마지막 15분봉에 붙인다.
- SCR 3단(저장소 `btc_fractal.scr3`, 같은 TF): Stoch fast 5 / CCI 20 / RSI 14가 3봉 안에 모두 과매수선(80/100/70) 아래로
  이탈 = 위 이탈(on_s), 과매도선(20/−100/30) 위로 돌파 = 아래 돌파(on_l).

## 신호 (TF마다 8개, 1d는 SCR 문 3개를 뺀 5개 → 4×8 − 3 = 29개)

교차 상대 A = ADX 선, L = 20 수준, M = 반대쪽 DI.

- TR-A / TR-L (추세 시작 따라가기): PDI가 상대를 위로 넘으면 롱, MDI가 상대를 위로 넘으면 숏.
- TR-M: PDI가 MDI를 위로 넘으면 롱, MDI가 PDI를 위로 넘으면 숏.
  (끝 해석의 M 읽기 "PDI 데드 = MDI 골든"은 이것과 같은 사건이라 따로 세지 않는다.)
- EN-A / EN-L (움직임 끝 되돌림): PDI가 상대 아래로 내려가면(데드) 숏, MDI가 상대 아래로 내려가면 롱.
- ES-A / ES-L / ES-M (SCR 선행 + DMI 확인): 같은 TF에서 SCR 위 이탈(on_s)이 8봉 안에 있었고 PDI 데드(상대 A/L/M) → 숏.
  거울: SCR 아래 돌파(on_l) 8봉 안 + MDI 데드 → 롱. 1d는 하루 봉 8개 안의 겹침이 너무 드물어 빼고 등록한다.
