# BTCUSDT SRC Adaptive TF 사전 등록

2026-11-01, 결과를 보기 전에 등록한다. 사용자가 Pine 전략 "SRC Adaptive TF (Long/Short)"를 보내며 "너가 조금씩 조절해가면서 15분봉이나 1시간봉이나 30분봉으로" 시험하라고 했다. 코드는 `docs/backtests/raw/btc_src.py`, numpy가 필요하다. 주문과 연결되지 않는다.

## 원본 규칙
- Stoch 14(20/80), CCI 20 종가 기준(±50), RSI 14(36/84)
- 롱: 직전 봉 과매도 개수 ≥ 2이고 이번 봉 상향 돌파 개수 ≥ 1. 숏은 반대
- 청산: 지표 2개 이상이 반대쪽 극단이거나 반대 신호. 손절 15%, 트레일링 25%
- 신호는 봉 마감, 체결은 다음 봉 시가. 손절·트레일도 봉 마감 판정 뒤 다음 시가
- 원본 수수료는 0%다. 비현실적이어서 한쪽 0.05%로 친다
- 추세 필터(기본 꺼짐): 12봉 안 DMI·MACD·OBV 골든 3개 중 2개 + MA50 위. 숏은 반대

## 조절과 평가
값: 직전 개수 1·2·3, 돌파 개수 1·2, 청산 개수 1·2·3, 추세 필터 끔·켬 = 36개. 손절 두 묶음: 원본 15%/트레일 25%, 사용자 규칙 1%(봉 안 손절선 체결, 트레일 없음). 프레임 15분, 30분, 1시간.

최고 칸을 고르지 않는다. 2020~2026 해마다 그 전 해들의 로그 수익 합 1위(거래 30회 이상, 합이 0 이하면 관망)를 골라 그해에 적용한다.

## 판정 (2020~, 모두 넘어야 통과)
연도별 선택이 비용 0.05%·0.10%에서 플러스, 2025~26 플러스, 수익/낙폭이 보유 0.54 초과. 원본값은 달 안 이동 p < 0.0083 (0.05/6), 상위 5건 제외 1.0 초과. 통과하면 레드팀을 거친다.
