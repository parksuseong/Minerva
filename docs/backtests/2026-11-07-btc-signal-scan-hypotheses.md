# BTCUSDT 선물: 패턴·거래량·지표 신호 전수 탐색(FDR) 사전 등록

2026-11-07 12:50 KST. 이 문서는 결과를 보기 전에 등록한다. BTC 시험 문서로는 125번째다. 사용자: "이미지 패턴도 보고 거래량도 조합해보고 너가 상상할 수 있는거 다 해봐 기본적으로 이건 퀀트야". 코드는 `raw/btc_signal_scan.py`이고, 주문과는 연결되지 않는다.

앞선 패턴 시험(11/1~11/3: 스윙 패턴, 패턴 12종 대조, 돌파+거래량, 패턴 상황)은 현물·패턴별 손절·목표로 봤고 쓸 칸이 없었다. 이번에는 같은 탐지기를 다시 쓰되, 신호를 한 틀에 모아 같은 청산·같은 비용으로 비교하고, **발견 구간(2020~2023)에서만 고른 뒤 확인 구간(2024~)에서 한 번만 본다.** 다중 검정은 전체 칸 수에 Benjamini–Hochberg를 건다.

## 신호 (봉 마감에 판단, 롱 정의 + 정확한 거울 숏)
지그재그는 1%·2%·4%이고 **확정된 피벗만** 쓴다(극점에서 크기만큼 되돌린 봉에 확정). 봉은 15분·1시간·4시간이다.
- A 패턴(지그재그 기하)
  - 기존 탐지기 그대로: 이중 바닥(DB), 첫 눌림(DBP), 삼중 바닥(TB), 역머리어깨(IHS), 가틀리·배트·크랩·버터플라이(하모닉 한 묶음 HARM), AB=CD, 쓰리 드라이브, 골든 포켓, 상승 삼각(ATRI). 기존 지정가형(하모닉·AB=CD·쓰리 드라이브·골든 포켓)은 패턴이 완성돼 대기가 시작되는 봉을 신호로 보고 시장가로 들어간다(이번 시험은 청산을 통일하므로).
  - 새로 넣음: SFP(직전 확정 저점 아래로 찌르고 그 위에서 마감), CHoCH(직전 두 피벗이 LH·LL인 하락 구조에서 종가가 직전 확정 고점을 넘음), 깃발(직전 다리가 크기의 2배 이상 상승, 다음 되돌림이 그 다리의 50% 이하, 종가가 다리 고점을 넘음), 콰지모도(L1 → H1 → LL → HH 뒤 가격이 L1 수준으로 돌아온 봉)
- B 거래량·VPA
  - VBRK: 종가가 직전 확정 고점을 넘고 그 봉 거래량 z ≥ 2(직전 20봉 기준)
  - VPA: 몸통 ≤ 범위의 30%, 거래량 z ≥ 2, 저가가 직전 20봉 최저
  - LVRT: 저가가 직전 확정 저점의 +0.2% 안에 닿고 종가는 그 위, 아랫꼬리 ≥ 범위 50%, 거래량 z ≤ −0.5
  - CLMX: 직전 봉이 음봉·거래량 z ≥ 3·범위가 직전 100봉 상위 5%, 이번 봉 종가가 그 봉 중간값 위
  - TKC / TKM: 시장가 매수 비율(20봉 합)의 과거 2,000봉 z ≤ −1.645(하위 약 5%)면 롱(TKC, 역추세) / z ≥ +1.645면 롱(TKM, 추세). 순위 분위수 대신 z로 근사한다(계산량 때문).
  - OBVD: 새로 확정된 저점이 직전 확정 저점보다 낮은데 그 봉의 OBV는 더 높음
- C 지표
  - RSID / CCID / STOD: 새로 확정된 저점이 직전보다 낮고 지표는 더 높으며, 저점 봉 지표가 RSI < 30 / CCI < −100 / Stoch < 20
  - SCR3: 기존 `scr3`(Stoch·CCI·RSI 세 단 돌파)
  - WSMA: 길이 = 마지막으로 끝난 다리의 봉 수인 SMA. SMA가 오르는 중이고 저가가 SMA에 닿고 종가가 SMA 위
- D 문(모든 신호에 곱함): 없음 / R1 방향 일치(마감된 일봉 CCI20·RSI14 방향, 롱은 +1, 숏은 −1) / 거래량 확인(신호 봉 거래량 z ≥ 1.5)

## 체결과 청산
- 신호 봉 마감 다음 15분봉 시가에 시장가로 들어간다. 칸마다 포지션은 하나다(보유 중 신호는 버린다).
- X1: 1% 손절 + 2% 목표(최대 3일). X2: 1% 손절 + 4시간 시간 청산. X3: 1% 손절 + 1일 시간 청산.
- 같은 15분봉에 손절과 목표가 함께 닿으면 손절로 본다. 갭이면 시가로 체결한다.
- 비용 한쪽 0.05%, 펀딩을 더한다.

## 칸과 고르는 방법
- 칸 = (신호, 봉, 지그재그 크기, 문, 청산). 롱과 거울 숏을 합친 거래로 본다. 지그재그를 쓰지 않는 신호는 크기 칸이 하나다.
- 발견 구간 거래 60회 이상인 칸만 검정한다. 거래당 순손익의 t값으로 단측 p를 내고, **검정한 칸 전체**에 BH q = 0.10을 건다. 검정한 칸 수를 보고한다.
- 살아남은 칸만 확인 구간을 한 번 본다. 통과 조건(모두):
  1. 확인 구간 거래 30회 이상
  2. 확인 구간 롱+숏 거래당 > 0, 롱과 숏 각각 ≥ 0
  3. 비용 한쪽 0.10%에서도 확인 구간 거래당 > 0
  4. 15분봉 시작을 5분 옮겨도(모든 봉) 확인 구간 거래당 > 0
- 살아남은 칸에는 진입 시각 원형 이동 대조(200회, 발견 구간)도 적는다.
- 참고로 발견 구간 t값 상위 10칸은 FDR을 못 넘어도 확인 구간 값을 함께 적는다(판정 아님, 표시한다).
- 통과해도 바로 실전에 쓰지 않는다. 레드팀과 새 자료 전진 확인을 거친다.
- 계산이 60분을 넘으면 지그재그를 2%만 남기고 그 사실을 적는다.
