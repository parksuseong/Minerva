# BTCUSDT 15분봉 스윙 라벨 매매 사전 등록

2026-11-01, 결과를 보기 전에 등록한다. 사용자: "라벨 텍스트가 HL과 LL, HH, LH가 매매 기준이 되면 괜찮겠는데?". 코드는 `docs/backtests/raw/btc_swing_label.py`다. 주문과 연결되지 않는다.

## 라벨의 확정 시점
RSI Swing 지표(RSI 7, 70/30)의 라벨은 RSI가 반대 극단에 닿아야 확정된다. 저점 라벨은 RSI ≥ 70이 된 봉에서, 고점 라벨은 RSI ≤ 30이 된 봉에서 굳는다. 저점이 직전 저점보다 높으면 HL, 낮으면 LL, 고점이 직전 고점보다 높으면 HH, 낮으면 LH다. 그 전에 라벨을 쓰면 미래 정보다. 모든 규칙은 확정된 봉의 마감으로 판단한다.

## 규칙
- S1: HL 확정 시 롱, LH 확정 시 숏. 반대 신호에서 뒤집기
- S2: S1이되 추세 일치만. 직전 고점이 HH일 때의 HL 확정만 롱, 직전 저점이 LL일 때의 LH 확정만 숏
- S3: 구조 돌파. 종가가 확정된 마지막 고점 라벨 위로 처음 올라서면 롱, 마지막 저점 라벨 아래로 처음 내려가면 숏. 반대 신호에서 뒤집기
- S4: S3이되 추세 일치만. 마지막 두 저점이 HL일 때 롱, 마지막 두 고점이 LH일 때 숏

모두 다음 봉 시가 진입, 손절 1%, 비용 한쪽 0.05%. 값을 찾지 않는다.

## 판정 (2020~, 모두 넘어야 통과)
비용 0.05%·0.10% 플러스, 2025~26 플러스, 위치 이동 p<0.0125(0.05/4), 상위 5건 제외 1.0 초과, 거래 100회 이상, 수익/낙폭이 보유 0.54 초과. 최근 2개월을 함께 낸다.

## 레드팀 (S3·S4 기각, S4만 체결 추적 조건부)
미래 정보와 치명적 버그는 없다. 잘림·교란 시험, 독립 재구현, 5분봉 손절 대조가 맞았다.

- 라벨 정의 불일치 지적: `signals`와 `confirmed`의 저점이 379곳 달랐다. Pine 원문 끝부분("If last state was oversold … ll := low")을 대조해 `confirmed`가 맞음을 확인했다. `signals`의 저점 추적 누락을 고쳤다. 매수·매도 신호와 S1~S4는 바뀌지 않고, 라벨 체결 비교값만 바뀐다.
- 알파 증거 없음: 월 베타 0.08/0.10, 선형 알파 t 1.09/1.40, 상승·하락 분리 후 −1.73/−0.67이다. 같은 달 위치 이동 p 0.454/0.461, 같은 분기 0.231/0.272다. 같은 달 비교는 규칙에 불리하게 치우쳐서 "시점 우위의 증거가 없다"까지만 말한다.
- 집중: 플러스 달 39%/34%, 상위 5개월이 로그 손익의 118%/113%, 2020년이 50%/41%다. 2021+는 S3 +12.1%, S4 +18.2%, BTC +18.4%다. 2024+는 BTC보다 낮다. 2025+ 플러스는 숏 덕분이고 롱만이면 −6.1%/−5.0%다.
- 안정성은 좋다: 1시간봉 48칸 중앙값 +21.7%/+26.8%, 모두 플러스, 등록값 순위 8/12·7/12다. 판정 밖 2018~19도 +67.9%/+20.8%로 BTC −27.6%보다 낫다. 하지만 라벨 없는 N시간 종가 돌파도 2020+ +21~42%라 라벨 고유 우위의 증거가 없다. 2021+는 S4가 돌파(+3~9%)보다 낫지만 사후 비교다.
- 현실 비용(펀딩 가정): 무기한 현실 S3 +13.6%, S4 +21.2%, 2025+ −1.9%, +4.3%. 비관 +4.6%, +13.9%. 손익 분기 손절 밀림 0.31%, 0.59%(2025+ 0.03%, 0.17%).
- 다중 비교: 1시간봉 6개 Bonferroni 0.23/0.31, 세션 전체로는 1.0이다. 1시간봉 등록과 실행 스크립트가 같은 시각이라 사전 등록 증거가 약하다. 8~10월 값은 사용자가 흥미를 느낀 구간이라 증거에서 뺀다.
- 운영: 최장 연패 34회(−31%)/23회(−22%), 고점 회복 1,079일/813일, 12개월 마이너스 31%/21%, 연 수익 거래 9회/5회다. 전진 판별에 11.9~18.6년이 필요해 추적으로 우위를 가릴 수 없다.
- 레드팀 추정: S4 연 +5~12%, 낙폭 −40% 안팎, S3 연 0~5%(측정값 아님). S4는 "종이 추적 후보"로 부르지 않고 "등록 판정 탈락 규칙의 체결 추적"으로만 쓴다. 15분봉만 시험하라는 지시의 예외인지 사용자 확인이 필요하다.
