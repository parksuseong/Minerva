주의: 승률은 익절 < 손절이면 저절로 높아진다. 비용 포함 손익분기 승률 p* = (S + 0.12%) / (T − 0.08% + S + 0.12%)
(진입 테이커 0.05% + 미끄러짐 0.01%, 익절 메이커 0.02%, 손절 테이커 0.05% + 0.01%). 예: T 1% / S 3% → p* ≈ 77%.
그래서 **같은 손절·익절·보유의 무작위 진입과 비교한 승률 초과분**을 본다.
