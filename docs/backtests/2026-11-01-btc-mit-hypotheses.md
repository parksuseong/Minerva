# BTCUSDT mit strategy 사전 등록

2026-11-01, 결과를 보기 전에 등록한다. 사용자가 TradingView Pine 전략 "mit strategy"(4,132줄, ZPayab 표기)를 보내며 "이번엔 이거로 해봐"라고 했다. 코드는 `docs/backtests/raw/btc_mit.py`, numpy가 필요하다. Pine 원문은 저장소에 넣지 않는다. 주문과 연결되지 않는다.

## 기본 설정 그대로 옮긴 규칙
- Range Filter: 종가, 기간 100, 배수 3. 거리 = EMA(EMA(|Δ종가|, 100), 199) × 3. 필터는 기존 재귀식. 상승 = 종가 > 필터, 필터 상승 카운트 > 0, 종가 변화 있음
- RQK: 종가, 창 27봉(0~26), h 8, r 8. 가중 w = (1 + i²/(2·h²·r))^(−r). 상승 = 전 봉 값 < 이번 값. 과거 봉만 쓴다
- 신호: Range Filter 방향 + RQK 일치, Range Filter 연속 3봉 이내, 번갈아 나오는 신호만
- 체결: 신호 봉 종가(`process_orders_on_close`), 반대 신호면 뒤집기, 비용 한쪽 0.05%, 슬리피지 1틱은 무시할 크기
- 청산 E1(원본 기본값): 익절 2%, 손절 1%. E2(원본 옵션 Opposite Signal + 사용자 손절 1%): 반대 신호, 손절 1%
- 한 봉에서 익절과 손절이 함께 닿으면 손실로 친다. TradingView의 봉 경로 가정 값도 참고로 낸다

1시간봉과 15분봉, 총 4개다. 값을 찾지 않는다.

## 판정 (2020~, 모두 넘어야 통과)
비용 0.05%·0.10% 플러스, 다음 봉 시가 체결 + 손절 밀림 0.10%에서 플러스, 2025~26 플러스, 위치 이동 p<0.0125, 상위 5건 제외 1.0 초과, 거래 100회 이상, 수익/낙폭이 보유 0.54 초과. 최근 3개월을 함께 낸다.

## 알려진 한계
