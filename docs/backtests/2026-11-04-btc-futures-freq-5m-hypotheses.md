# 선물, 5분봉 SCR 진입으로 이틀에 한 번 이상 매매 (목표 +1% 이상)

2026-11-04 00:37 KST, 결과를 보기 전에 등록한다. 15분봉 진입은 1년 180회를 못 넘었다(`2026-11-04-btc-futures-freq-hypotheses.md`). 진입 신호만 5분봉 SCR 3단으로 바꾸고 나머지(추세 필터 F1~F3, 청산 X2~X5, 손절 1.5/3%, 선물·펀딩·3배, 고르기 2020~23, 판정 2024~, 판정 1~4·6)는 그대로 둔다. ATR은 15분봉 것을 쓴다. 판정 5(봉 이동)는 5분봉보다 짧은 자료가 없어 뺀다. 코드는 같은 `raw/btc_futures_freq.py --factor 1`이다.
