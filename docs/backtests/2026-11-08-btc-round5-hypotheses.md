## 4. 나눠 들어가기 (K2 진입, 새 모의 매매)
반 크기로 진입, 조건이 오면 나머지 반을 더한다(한 번만). 목표 = 평균가 ± 0.5×ATR(첫 진입 신호 봉 ATR), 재난 손절 = 첫 진입가 ∓7%, 96봉 시간 청산, 포지션 중 새 신호는 무시.
- S1: 첫 진입가에서 1×ATR 불리하면 추가(그 가격 지정가 체결로 가정, 시가가 넘었으면 시가).
- S2: 2×ATR 불리하면 추가.
- S3: 포지션 중 zP가 더 깊은 극단(≤ 설계 0.5% 분위 −2.90946 / ≥ 99.5% 4.43850)에 닿은 봉 다음 시가에 추가.
손익·최악 평가손익은 **전체 계획 크기(1.0) 기준**으로 적는다(반만 들어간 동안도 같은 기준). 10배 청산 판정은 앞과 같다(10 × 최악 ≤ −95%). 수수료는 체결한 크기마다, 펀딩은 크기에 맞춰 나눈다.

## 5. 변형 수와 판정 (본페로니 N = 83)
16 신호 × 5 청산 = 80 + 나눠 들어가기 3 = **83**. (오늘 밤 누적 5,171 + 83 = 5,254.)
**통과** = 아래 모두:
1. 검증: 승률 ≥ 70%, 10배 수익 > 0, 청산 0, 거래 ≥ 30. 설계: 10배 청산 0, 1배 수익 > 0.
2. 무작위 기준: 같은 청산·같은 수의 무작위 진입(2,000회) 대비 검증 1배 수익의 정규 근사 p × 83 < 0.05.
3. **새 구간 확인**(계산할 수 있는 신호): 승률 ≥ 70%, 10배 수익 > 0, 청산 0, 거래 ≥ 20. 새 구간을 못 보는 G6·(일부만 보는 G1·V4)는 통과해도 "약한 통과"로 적는다.
보고: 통과 후보 전부, 없으면 검증 승률 상위 2개(검증 30회 이상, 설계·검증 청산 0) + 새 구간 결과. 차트(롱 원·숏 삼각형, 롱 진입·숏 청산 초록 / 롱 청산·숏 진입 빨강, Stoch·CCI·RSI 칸). 결론 전 레드팀.
