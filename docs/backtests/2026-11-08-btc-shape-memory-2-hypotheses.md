## 질문

1. 같은 모양이 3시간에 걸쳐 나오든 2일에 걸쳐 나오든 같은 모양으로 보면(시간 늘림·줄임) 방향을 맞히나?
2. 15분봉 대신 1시간·4시간·일봉 모양은 방향을 더 잘 맞히나? (핵심 질문: 일치율 대비 적중률 보정 곡선)

## 자료와 기억 규칙

- 가격: 2020-01 이후 바이낸스 USDⓈ-M 선물 15분봉, 그 전은 현물 15분봉(기억에만 씀). 매매·평가는 선물 + 펀딩.
- 기억은 결정 시점 전에 결과(지평)까지 확정된 모양만 쓴다. 기억 항목마다 "결과 확정 시각 = 끝 + 지평"으로 정렬해 그 이전만 본다.

## 변형 (40개)

### TW: 시간 늘림·줄임 (16개)
- 창 길이 7가지(15분봉 16·32·64·96·192·288·480봉 = 4시간~5일)의 로그 종가 경로를 64점으로 다시 뽑아(선형 보간) 평균 빼고 단위 길이.
  기억은 7가지 창을 모두 2시간 간격으로 담는다. 각 기억의 결과 = 창 길이의 1/4 뒤 방향과 (수익 / 창 안 로그 범위).
- 질의 창 QW ∈ {96봉(1일), 192봉(2일)}, 1시간마다 결정. 거래 지평 = QW/4 (6시간, 12시간).
- 찾기 방식 2가지: C = 상관(내적) 상위 50, D = 상관 상위 200을 DTW(사코에-치바 띠 ±6점)로 다시 줄 세워 상위 50.
- 문턱 q ∈ {0.6, 0.7}. 수수료 T(시장가 진입·청산), M(지정가 진입 메이커 0.02%, 4봉 안에 뚫고 지나가야 체결, 청산은 시장가).
- 2 × 2 × 2 × 2 = 16.

### HF: 큰 봉 경로 (12개)
- 1시간·4시간·일봉(15분봉을 묶어 만듦)의 최근 32봉 로그 경로(평균 빼고 단위 길이). 결과 지평: 1시간봉 → 4봉(4시간), 4시간봉 → 6봉(1일), 일봉 → 3봉(3일).
- 큰 봉이 마감되는 15분봉에서 결정, K = 50, q ∈ {0.6, 0.7}, 수수료 T/M. 3 × 2 × 2 = 12.

### ZN: 기간까지 지운 지그재그 (8개)
- 마지막 6다리의 높이 비율만(기간 성분 없음). 15분봉(1.5×ATR15)과 4시간봉(1.5×ATR4h) 두 가지, K = 50, q ∈ {0.6, 0.7}, T/M. 2 × 2 × 2 = 8.

### U: 어느 봉이든 신호 (4개)
- HF 1시간·4시간·일봉 중 하나라도 신호(같은 q)면 진입, 하루 1회 이상을 노린다. 포지션은 한 번에 하나, 지평·익절·손절은 신호를 낸 봉 기준. q ∈ {0.6, 0.7}, T/M. 4.

## 매매 공통

- 롱: 이웃 오를 확률 ≥ q 이고 평균 결과 > 0. 숏: ≤ 1−q 이고 평균 결과 < 0.
- 진입: T는 다음 15분봉 시가(추격 한도 1%, 15분·4시간·일봉 방향이 모두 같으면 3%), M은 신호 봉 종가 지정가.
- 익절 = 손절 = ATR15 × √(지평 봉 수) (지평만큼의 보통 움직임), 지평이 지나면 종가 청산. 한 번에 한 포지션.
- 5배 결과가 머리, 1배 참고. 청산 모델: 5배 × 최악 평가손 ≤ −95%면 청산.
