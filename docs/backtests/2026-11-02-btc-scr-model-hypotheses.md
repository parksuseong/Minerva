# BTCUSDT 30분봉 과거 SCR 3단 매매로 학습한 승리확률 모델 사전 등록

2026-11-02, 결과를 보기 전에 등록한다. 사용자: "과거 scr을 통해 매매한 것을 기반으로 학습해서 가장 이상적인 모델을 만들어 승리확률". 코드는 `docs/backtests/raw/btc_scr_model.py`. 주문과 연결되지 않는다.

## 표본과 승패
5분봉에서 묶은 30분봉, 2017-09~2026-11-02의 SCR 3단 신호(롱·숏) 전부. 신호 봉 마감, 다음 시가 진입, 손절 1%(갭은 시가), 반대 SCR 3단 원신호 다음 시가 청산, 상한 없음(SCR 본래 방식). 승리는 비용(한쪽 0.05%) 뒤 +0.1% 초과.

## 특징 (신호 봉 마감까지의 정보, 숏은 대칭)
Stoch·CCI·RSI 값과 직전 3봉 극값, SCR 5상태, 이평 4상태, 볼린저 4위치, SMA20·60·120·240 거리, 3·12·48·96봉 흐름, 4시간봉·일봉 SCR 방향(마감된 봉, CCI>0·RSI>50), 30분봉 RSI 다이버전스, 거래량 배수와 흡수 봉(거래량 2배 이상·몸통 작음), 직전 6시간 같은/반대 방향 패턴 완성(고친 탐지기), 시간대, 변동성, 롱 여부.

## 모델 고르기와 시험
- 학습 2017~2022, 검증 2023, 시험 2024-01-01~2026-11-02
- 검증 AUC로 고른다: 능형 로지스틱(λ 3·30·300), kNN(k 60), 둘의 평균
- 진입 문턱: 학습만으로 맞춘 모델의 검증 구간 매매(포지션 하나)에서 30회 이상 중 평균 최대
- 시험: 학습+검증으로 다시 맞춘 모델, 같은 문턱

## 판정 (모두 넘어야 통과)
1. 시험 AUC의 일 단위 블록 부트스트랩 95% 하한 > 0.5
2. 시험 매매 30회 이상, 비용 0.05%·0.10%에서 평균 플러스, SCR만(같은 기간 모든 신호, 포지션 하나)보다 평균이 높다
3. 30분봉 시작 15분 이동 실행에서도 2 유지
4. 상위 5거래를 빼도 플러스
통과하면 레드팀을 거친다.

## 알려진 한계
특징 일부(패턴 탐지기, 다이버전스 정의)는 오늘 같은 자료를 보며 만들었다. 숏은 선물이 필요하고 펀딩은 넣지 않는다.

## 결과
**탈락(판정 1, 2).** 신호 학습 916, 검증 140, 시험 608개. 기본 승률 14.1% → 22.9% → 25.2%.

- 검증으로 고른 모델: 로지스틱(λ 30)과 kNN 평균, 검증 AUC 0.598(15분 이동 실행은 0.509로 검증에서도 신호가 거의 없음)
- 판정 1: 시험 AUC 0.543, 일 단위 블록 부트스트랩 95% 0.493~0.591. 15분 이동 0.552(0.500~0.604). 0.5를 포함해 우연과 구분되지 않는다
- 판정 2: 문턱 격자 하한 0.20 이상에서 검증 매매 30회가 되는 문턱이 없어 매매가 성립하지 않는다. 학습 기본 승률 14%라 학습 모델의 확률 대부분이 0.2 아래였다. 격자 범위는 등록에 적지 않았다
- 시험 신호를 확률 5분위로 나누면 실제 승률 16.1%, 28.2%, 26.6%, 28.7%, 25.0%(각 약 124개). 가장 낮은 분위만 약하다
- 보정: 기본 승률이 시기마다 달라 확률이 낮게 나온다(0.2 미만 구간 예측 13.6%, 실제 24.8%)
- 참고: 같은 시험 구간 SCR 3단만(포지션 하나) 449회, 거래당 +0.056%(한쪽 0.10% −0.044%), 15분 이동 −0.013%

레드팀(통과): 상위봉 방향, 패턴 창, 다이버전스 피벗, 거래량 평균, 변동성 중앙값 모두 미래 정보가 없다. 반대 해석: 두 실행의 점추정이 0.54~0.55이고 보정표 승률이 확률 순으로 오르므로 "약한 신호가 없다"까지 증명된 것은 아니다. 상한 없는 보유라 2022년 말 신호 몇 개가 2023년 가격으로 라벨을 받는다(영향 미미).
