## 사건
- 급락: 15분봉 i의 종가에서 다음 16봉(4시간) 안의 저가가 종가보다 3% 이상 낮다. 봉마다 붙이는 라벨이다(y=1).
- 급등(거울): 다음 16봉 안의 고가가 종가보다 3% 이상 높다.
- 사건 수(재현율용): y=1인 봉 중 앞선 96봉(24시간) 안에 다른 사건 시작이 없는 봉을 사건 시작으로 센다.
- 기본 비율: 구간 안 모든 봉 중 y=1의 비율.

## 특징 (모두 봉 i 마감 때 알 수 있는 값)
- 15분·1시간·4시간·일봉 Stoch 5, CCI 20, RSI 14 값과 직전 봉 대비 변화(마감된 봉만)
- 4시간 과매수 꺾임 R: 마지막 마감 4시간봉 k에서 Stoch[k−3..k−1] 최대 > 80, Stoch[k] < Stoch[k−1], CCI[k−3..k−1] 최대 > 100, CCI[k] < CCI[k−1]
- 숏 스퀴즈 급등 P: 지난 96봉 안의 봉 j가 다음을 모두 만족한다. 15분 거래량 z ≥ 4(직전 96봉 평균·표준편차 기준, j 제외), j 봉 상승, j까지 24시간 수익률 ≥ +2.5%, j가 끝나는 1시간의 OI 변화 ≤ 0. OI가 없는 기간(2021-11 이전)에는 P가 거짓이다.
- 급등 뒤 수축: 최근 48봉 범위 / 일봉 ATR14, 최근 16봉 평균 거래량 z
- 일봉 방향 R1(CCI20 > 0이고 RSI14 > 50이면 +1, 둘 다 아래면 −1, 나머지 0)
- 상위 트레이더 롱/숏 비율(계정 수, `count_toptrader_long_short_ratio`) 값과 24시간 변화
- OI 1시간·4시간 로그 변화, 최근 펀딩, 직전 1시간 시장가 매수 비율, 실현 변동성(96봉), 2% 지그재그의 최근 확정 고점이 그 전 확정 고점보다 낮은지(낮은 고점), UTC 시각

## 가설 (고정)
- H1 = P 그리고 R
- H2 = H1 그리고 일봉 방향 ≤ 0
- H3 = H2 그리고 롱/숏 비율 24시간 변화 > 0 그리고 직전 1시간 매수 비율 < 0.45
- 거울(급등 예측): P′(거래량 z ≥ 4인 하락 봉, 24시간 수익률 ≤ −2.5%, OI 변화 ≤ 0), R′(4시간 과매도 반등: Stoch 최소 < 20 뒤 상승, CCI 최소 < −100 뒤 상승), 일봉 방향 ≥ 0, 롱/숏 비율 하락, 매수 비율 > 0.55
- 신호 정리: 깃발은 켜진 뒤 24시간 안의 재점화를 하나로 본다(첫 봉만).
- 단변량: 연속 특징은 발견 구간의 상·하위 10% 경계로 나눠 깃발로 만들고 상승 배수(lift)를 적는다. 기술용이고 판정에 쓰지 않는다.
- ML: XGBoost(깊이 4, 300회, 학습률 0.05, 열 0.8, 행 0.8, 클래스 가중), 위 특징 전부. 해마다 다시 학습(2021~2026 예측, 학습은 2020부터 Y−1년 말까지, 끝 32봉 제외). 학습 표본은 2봉마다 1개.

## 구간과 판정
- 발견: 2020-01 ~ 2023-12. 확인: 2024-01 ~. 확인 구간은 한 번만 본다.
- 깃발 통과(모두): 확인 구간에서 정밀도/기본 비율 ≥ 2이고 정밀도의 Wilson 95% 하한 > 기본 비율, 정리한 깃발 ≥ 15회, 거울 깃발의 확인 구간 상승 배수 > 1.
- ML: 확인 구간 AUC, 점수 상위 1%·5%(전년 분위수 문턱)의 정밀도와 상승 배수. 상위 1% 상승 배수 ≥ 2이고 Wilson 하한 > 기본 비율이면 통과로 본다.
- 매매 환산(통과한 것만): 깃발이 켜지면(정리 뒤) 다음 15분봉 시작 5분 뒤 5분봉 시가에 시장가 숏(거울은 롱), 손절 1.5%, 목표 3%, 최대 16봉. 같은 봉에서 둘 다 닿으면 손절. 선물 + 펀딩 + 수수료 한쪽 0.05%. 거래 수와 거래당 순손익을 적는다.
- 사용자 사례(2026-11-05 12:00~13:00 UTC)에서 H1~H3와 ML 점수가 무엇을 말했는지 적는다. 확인 구간 안이고 사후에 고른 사례라 판정에는 쓰지 않는다.
- 다중 비교: 가설 깃발 3개 + 거울 3개 + ML 1개. 단변량은 기술용이다. 지금까지 BTC 시험은 약 131번이다.
