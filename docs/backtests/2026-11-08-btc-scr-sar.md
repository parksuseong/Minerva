## 1. 신호 (실험실과 같은 계산)

Stoch = 날 %K(평활 없음), CCI = hlc3 평균편차, RSI = 와일더. 롱: 최근 W봉(현재 포함) 안에 각 지표가 아래 기준선을 위로 다시 넘어온 것이
need개 이상 → 조건이 처음 맞은 봉에만 신호. 숏: 위 기준선을 아래로(거울). 같은 봉에 롱·숏이 같이 나오면 둘 다 무시.
봉: 선물 1분봉(`~/.minerva/data/btc/futures/1m/` + 공개 GET 꼬리)으로 만든 UTC 15분봉, 마감 봉만.

## 2. 매매 모형

- 체결: 신호 봉 마감 → 다음 봉 시가(= 마감 직후 1분봉 시가). 적대 검사로 +1분(다음 1분봉 시가).
- SAR: 처음 신호에 진입, 반대 신호에 청산 + 반대 진입, 같은 방향 신호는 유지. 손절·목표 없음. 창 시작에는 무포지션, 창 끝에 시가로 청산.
- 비용: 테이커 0.05%/쪽(뒤집기 = 청산 + 진입), 펀딩(8시간 실제 요율, 진입~청산 사이 정산 시각마다 명목 × 요율), 미끄러짐 0(적대 검사 +0.02%/쪽).
- 레버리지: 5배 주 결과, 1배·3배 참고. 계좌 100%를 증거금, 매 거래 복리.
- 강제 청산: 1분봉 고가·저가로 거래 중 최악가를 잰다. 롱은 1/L − 수수료 + (최악/진입 − 1) ≤ 0.004 × (최악/진입)이면 청산(유지증거금 0.4%,
  BTCUSDT 1구간). 5배 롱 ≈ −19.6%, 숏 ≈ +19.5%. 청산 = 계좌 −100%(그 뒤는 0으로 둔다), 횟수는 거래 단위로 따로 센다.
- 추격 제한(상시 규칙): 진입가가 신호 봉 종가에서 거래 방향으로 1% 이상이면 진입 안 함(3% — 15분·4시간·1일 마감 봉 CCI20>0·RSI14>50
  방향이 모두 거래 방향일 때). 걸리면 기존 포지션은 청산하고 무포지션으로 다음 신호를 기다린다. 걸린 횟수를 적는다.
- 거래 승률 = 수수료·펀딩 뺀 순손익 > 0 인 거래 비율. 최대 역행(MAE) = 거래 중 1분봉 최악가의 진입가 대비 %.

보고 숫자는 창마다 무포지션에서 다시 돌린 정밀 모의(추격 제한 포함)로 낸다.

  70% 이상 후보가 없으면 같은 조건에서 승률 조건만 빼고 고른다("70% 후보 없음"으로 적는다).

## 6. 실험실 "4시간 뒤 맞는 방향" vs 거래 승률

실험실 숫자 = 신호마다 (신호 봉 종가 → 16봉 뒤 종가)가 신호 방향이면 맞음. 롱·숏 신호를 모두 세고, 같은 방향 연속 신호도 각각 센다. 수수료·펀딩·보유 기간 무관.
거래 승률 = 실제 SAR 거래(진입 → 반대 신호에 청산)의 순손익 > 0 비율. 둘을 같은 창에서 나란히 적는다.
