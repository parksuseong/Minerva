# BTCUSDT 일봉에 주식 실전 규칙(SCR + VIX) 롱·숏 사전 등록

2026-11-06 17:30 KST. 이 문서는 결과를 보기 전에 등록한다. 사용자 질문은 "비트코인 롱숏좀 해보는걸 scr에 vix까지 같이 봐봐 주식과 같은 조건으로"다. 코드는 `raw/btc_stock_rule.py`이고 주문과는 연결되지 않는다. BTC 시험 문서로는 89번째다.

## 롱: 국내 실전 규칙 그대로
코드는 `minerva.strategy.daily.TM_RULE`(`Rule(level=1, above_ma=50, hold=20, stop=0.10, vix="calm", align=True)`)이고, `backtest.run`과 `backtest.live_context`를 그대로 부른다.

진입: 아래 조건이 모두 맞는 날, 다음 봉 시가에 들어간다.
- SCR 1단(Stoch 5가 20을 상향 돌파)에 처음 도달한 날
- 종가가 50일선 위
- VIX 관문이 열림(주봉 5주선 < 10주선, 지난주까지 마감된 주봉만 사용). 일봉 레짐은 그날보다 앞선 VIX 날짜만 쓴다.
- 직전에 마감된 주봉 종가가 20주선 위
- 직전에 마감된 월봉 종가가 10개월선 위

청산: 아래 중 먼저 오는 것.
- Stoch가 80을 하향 이탈한 봉의 종가
- 진입가 −10% 손절(갭이 나면 시가)
- 20봉 보유 만료(그 봉 종가)

비중: 관문이 열리면 레짐이 R0·R1이 되어 주식에서도 비중이 100%이므로, 진입은 늘 전액이다.

## 숏: 롱의 거울
주식에는 숏이 없어서 규칙을 뒤집어 만든다.

진입: 아래 조건이 모두 맞는 날, 다음 봉 시가에 들어간다.
- SCR 1단(Stoch가 80을 하향 이탈)에 처음 도달한 날
- 종가가 50일선 아래
- 직전에 마감된 주봉 종가가 20주선 아래
- 직전에 마감된 월봉 종가가 10개월선 아래

청산: 아래 중 먼저 오는 것.
- Stoch가 20을 상향 돌파한 봉의 종가
- 진입가 +10% 손절(갭이 나면 시가)
- 20봉 만료

숏의 VIX 조건은 셋을 본다. 주 판정은 mirror다.
- mirror: 관문 닫힘(주봉 5주선 ≥ 10주선, 변동성 상승)일 때만 숏
- calm: 롱과 같이 관문이 열려 있을 때만
- none: VIX를 보지 않음

## 판정 대상
- 주 판정(셋):
  - L: 롱만
  - S: 숏만, VIX mirror
  - LS: L과 S를 합침. 포지션은 하나이고, 비어 있을 때 먼저 나온 신호를 잡는다.
- 비교용:
  - L_novix: 롱에서 VIX 조건을 뺌
  - S_calm, S_none
  - LS_novix: L_novix와 S_none을 합침

## 자료와 비용
- 주 판정: 바이낸스 현물 5분봉(2017-09~)을 UTC 0시(KST 9시) 일봉으로 묶는다.
- 보조: USDT-M 선물 5분봉(2020-01~)에 펀딩비를 더한다. 보유 중 펀딩 시각마다 −방향×요율을 더한다.
- VIX: 야후 ^VIX 일봉 캐시(`~/.minerva/data/_VIX_max.json`). BTC 일봉 D(UTC)는 D+1 00:00 UTC에 마감되고, 미국 D일 VIX는 그보다 앞서 나온다. 그래도 실전 코드처럼 D보다 앞선 VIX만 써서 보수적으로 잡는다.
- 비용: 한쪽 0.05%, 민감도 0.10%.
- 표시: 1배와 3배. 3배는 거래마다 3×순손익을 복리로 쌓고 −100%에서 멈춘다. 최근 1년도 따로 보여 준다.

## 판정 (주 판정 대상마다, 모두 넘어야 통과)
일봉 규칙은 거래가 적어서 거래 수 기준을 15분봉 시험(구간마다 30회)보다 낮춘다. 결과를 보기 전에 정한 값이다.
1. 전체 30회 이상, 2017~2023과 2024~ 각각 10회 이상
2. 두 구간 모두 거래당 플러스(비용 0.05%), 전체는 0.10%에서도 플러스
3. 일봉 경계를 UTC 8시·16시로 옮겨도 2가 유지된다.
4. 상위 3거래를 빼도 전체가 플러스
5. VIX를 뺀 짝(L은 L_novix, S는 S_none, LS는 LS_novix)보다 전체 거래당 손익이 높다. VIX가 값을 더하는지 보는 기준이다.

통과한 대상은 같은 거래 수의 무작위 진입(같은 청산 규칙, 2,000회)과 비교해 p<0.05를 확인하고, 그다음 레드팀을 거친다. 통과해도 바로 실전에 쓰지 않고, 사용자에게 결과를 보고한 뒤 결정을 받는다.
