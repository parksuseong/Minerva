## 라벨과 학습
- 라벨: 신호 봉 다음 15분봉 시가에서 2일(192봉) 안에 +1.5%가 −1.5%보다 먼저 닿으면 1, 반대면 0, 둘 다 안 닿으면 뺀다(ML 앙상블과 같은 방식).
- 해마다 걸어가기: 시험 해 Y ∈ 2021~2026, 학습 2020-01~(Y−1 말 − 엠바고 200봉). 학습 표본은 3봉마다 1개.
- 모델
  - L1 로지스틱(표준화, C=0.05, 해석용 가중치)
  - XGBoost(깊이 4, 300회, 학습률 0.05, subsample·colsample 0.8, 씨드 5벌 = Y + 1000·k), 5벌 평균
- 문턱: 해 Y의 문턱은 해 Y−1 모델이 Y−1에 낸 예측(표본 밖)의 분위수다. q0.90/q0.95 이상이면 롱, q0.10/q0.05 이하면 숏(거울). 매매는 2022~2026.

## P1 매매
- 신호 봉 마감 + 5분의 5분봉 시가에 시장가 진입(지연 반영), ±1.5% 익절·손절(같은 5분봉에 둘 다면 손절), 최대 2일 뒤 종가 청산.
- 포지션 하나, 비용 한쪽 0.05% + 펀딩. 1배·3배, 일별 평가.
- 비교: AS4(128·135번, 같은 기간 표 값). 2023 CAGR/|낙폭| 4.70, 2024~ 0.56(연 +11.9%, 낙폭 −21.1%). AS4는 지정가 진입이라 체결 방식이 다르다는 점을 적는다.
- 변형 4개: L1-q90, L1-q95, XGB-q90, XGB-q95.

## P2 조합 규칙 탐색
- 조건: 특징 하나 × {학습 구간 10·25분위 이하, 75·90분위 이상}. 규칙은 조건 1~3개의 AND.
- 거울: 방향이 있는 특징(SCR 값·기울기, MACD, 이치모쿠 거리·차·후행, DI 차, EMA 거리, %B, 매수 비율, 펀딩, OI 변화)은 숏에서 분위수를 뒤집는다(10↔90, 25↔75). 방향이 없는 특징(ADX, ADX 기울기, +DI·−DI는 서로 바꿈, 구름 두께, 볼린저 폭, ATR%, 거래량 z)은 그대로 둔다(+DI↔−DI는 바꾼다).
- 거래 결과는 신호가 새로 켜진 봉(직전 봉은 꺼짐)마다 P1과 같은 체결·청산으로 계산한다(겹침 허용, 사건 단위).
- 탐색: 2020~2022(학습). 조건 하나 전부 → 상위 40개 조건과 전체 조건의 쌍 → 상위 40개 쌍에 세 번째 조건. 거래당 t(최소 100건, 롱+숏 합)로 상위 20개 규칙.
- 2023(검증)에서 상위 20개 중 3개를 고르고, 2024~(확인)에서 한 번만 본다. 상위 20개 중 2023·2024~에 플러스로 남는 수(과적합 비율)를 보고한다.

## 판정 (방식마다, 모두 넘어야 통과)
1. 2024~ 거래당 > 0, 3배 CAGR > 0
2. 2024~ 롱·숏 각각 거래당 ≥ 0
3. 비용 1.5배에서 2024~ 거래당 > 0
4. 같은 방향·같은 체결·같은 청산의 무작위 진입보다 낫다: 신호 시계열을 원형으로 민 1,000회 대비 p < 0.05(P1은 4개 변형이라 0.0125, P2는 최종 3개라 0.0167)
5. P1만: 씨드 한 벌씩 다섯 중 셋 이상 2024~ 거래당 > 0, CAGR/|낙폭|이 2023·2024~ 모두 AS4 이상

통과해도 실전에 쓰지 않는다. 추적으로 새 자료를 본다. 시간이 2.5시간을 넘으면 15분봉 특징을 빼고 그 사실을 적는다.
